1. 后盖先承托 PCB/显示、M2.5 螺钉、电池胶层、扬声器及线束；验 seam 平面度。
2. **不带硅胶帽**，前壳沿 -Z 对中下降至 seam；禁止用屏或螺钉拉平；确认屏仍有空气隙。
