# Pocket Pi G-V1 V4-RECT — 一体滑动按钮修订

**GEOMETRY_GATES_PASS_FUNCTIONAL_VERIFICATION_PENDING_NOT_PRINT_APPROVED** · `print_approved=false`。这是按用户授权修改后的打样候选；没有执行打印、下单或实物验收，不承诺首次打印成功。

这次主要解决两件事：把够不到开关的0127硅胶帽改为**外帽、凸缘、传力柱连成一件的PA12按钮**；把屏幕挡边下方的空气间隙从0.90收紧到0.40毫米。V1实物基线和官方板卡资料没有修改。

装配包络（包括默认按钮和螺头）：**102.90 × 78.26 × 16.45 mm**。

## 按钮怎样固定和活动

按钮从外侧插入。较大的凸缘留在壳体腔室里，锁上压框后就不能向外脱落；往内按时，凸缘最后碰到壳体肩面止挡。压框螺钉固定压框，**不能夹紧活动按钮**。按钮整体滑动，不依靠塑料弹片弯曲，也不粘、不套在主板小按钮头上。

默认外头Ø5.20、凸缘Ø7.40、主柱Ø3.60、末端接触柱Ø1.20毫米；凸缘厚1.80。三个导向位置的名义径向游隙均为0.30毫米。这是打印配合候选，不是厂商保证：孔收缩、两件偏差和表面粗糙仍可能导致卡滞。

小柱中心Z=-6.50，比官方模型按钮头中心约低0.10毫米，给上方PCB边缘留空间。尺寸来自官方STEP定位及新打印件的设计参数，不是新实物测量。

| 默认按钮 | 常态柱端到开关 | 整体可推进 | 碰壳体止挡时柱端越过原开关静态面 |
|---|---:|---:|---:|
| BAT_PWR | 0.250 | 0.550 | 0.300 |
| BOOT | 0.250 | 0.550 | 0.300 |

单位均为毫米。**这只说明柱端在图纸上能够到达开关，不能把最后一列当作原开关允许行程。** 原装开关准确料号、触发行程、最大安全位移、回弹力仍为null/UNVERIFIED；真实开关需要在壳体止挡之前触发，且不能被过压。

开关回弹只会把按钮推回到相互接触的位置。默认保留的空隙内没有主动回位力，按钮可能略有松晃；不能声称一定贴住外侧止挡。是否顺滑、能否回弹、是否误触和手感，需要整机实配。未默认增加弹簧、软胶或胶粘来掩盖这个问题。

检查覆盖实际按钮实体在**全轴向行程的连续扫掠**、四颗壳螺钉与其余紧固件锁紧后的避让、取出按钮的连续路径、凸缘两侧止挡，以及8个径向游隙边界姿态。只允许按钮柱端与官方模型的活动按钮区域接触，其他板卡/玻璃/开关壳体碰撞均失败。径向采样不等于任意倾斜或摩擦试验。

## 屏幕为什么收紧到这里

玻璃名义50.54×73.06、R2；下方窗口每边0.75，挡边遮住玻璃边缘1.00毫米。挡边内口48.54×71.06、R1。挡边厚1.50、径向基座1.60毫米，**没有额外加固**。挡边顶面降低到Z=2.60，屏幕相对顶面凹入1.90毫米。

V1设计总缝隙1.20、用户靠齐后测得约1.30毫米，差约0.10毫米。用户已确认所谓±0.10来自这一比较，**没有额外测过Z高度和平整度**；这既不能推出整机各方向±0.10，也不能用来消除翘曲风险。

本候选实交检查了屏幕相对前壳每轴±0.50、Z前移0.30毫米的5个姿态。它是明确标为UNVERIFIED的紧配合情景，不是重新认定打印精度。旧版±0.60XY/+0.60Z情景也继续计算：收紧后不再覆盖，碰撞值如实写在`screen_budget/previous_budget_sensitivity`，没有为了得到PASS而隐藏旧结果。

挡边与玻璃名义仍有0.40毫米空气隙。壳体靠自己的接缝止挡闭合，不贴泡棉填满此缝，不用玻璃撑平翘曲，也不靠拧螺钉把挡边压到玻璃。全高开口、圆角和导出STL仍检查；实际平整度、边缘触控、玻璃接触需实物验收。

## 装配和维护

1. 在后盖上固定原板/显示、电池、扬声器及线束，检查承座和接缝是否平整。
2. 不带按钮和压框，把空前壳从正面直降，确认屏幕没有被顶压；禁止用螺丝强拉平。
3. 装四颗壳螺钉。随后从侧面装默认按钮，再固定共用压框。确认压框拧紧后按钮仍自由活动。
4. 先检查松手时开关没有被持续按住，再检查能触发、能回弹；用记录表决定是否更换同批备选按钮。若需要用力挤入、无法回弹或开关先到极限，停止试装并修配合，不能继续加力。
5. 拆壳时先卸压框和两颗按钮，再卸壳螺钉抬起前壳。RESET仍可在装配后用Ø0.8直针操作，自由长度至少12毫米；自由长度不是允许插入深度。

## 其他保留事项

后板仍为3.50毫米并保留内部筋；局部让位地板1.55毫米，厚板不能保证工艺翘曲已经消失。USB保持13.2×7.3，独立插头本体通道和负对照继续检查。TF内藏、MIC入口候选和真实电池引线待验，与历史评审相同。

紧固件包络未改变：4颗M2.5×5机螺钉进原金属座；4颗2.0×6塑料用低头成形螺钉候选（头≤Ø3.6×1.2，非DIN7981承诺）；2颗1.6×5候选固定压框。实际SKU、孔缩、低扭矩成牙、滑牙及循环寿命仍未验证。电池胶层0.20毫米，不是屏幕泡棉。
