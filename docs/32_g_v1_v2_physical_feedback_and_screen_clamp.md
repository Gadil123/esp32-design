## 2. V2 结构决定

### 2.1 屏幕：从“自由窗口”改为“前向限位 + 圆角紧窗”

- 窗由官方 STEP 的**玻璃前面**导出：50.54×73.06、R2.0；不再用整块 DISPLAY 的工艺包络猜尺寸。
- 窗：**50.94×73.46、R2.2**，单边 **0.20mm**；总游隙 0.40mm（V1 为 1.20mm）。
- 屏唇：内口 **48.54×71.06、R1.0**，压住玻璃边缘 **1.00mm**；唇底面 z=**0.80**，玻璃前面 z=**0.70**，名义间隙 **0.10mm**；唇顶 z=**1.20**，屏相对唇顶凹 **0.50mm**。
  - 屏唇不是压屏结构：它只在 +Z 方向挡住玻璃，避免屏幕高出机身；不建议靠唇口给玻璃预压。
  - 唇下限位 0.10mm，可贴 **0.2mm 单面泡棉**（唇下 1.0mm 宽）；泡棉压缩后仍是软接触。没有泡棉时玻璃与唇不接触。
- 窗后加 **1.5mm 宽、2.0mm 高的内导框**（z −0.5…−2.5），从玻璃外侧导向显示模组；与模组单边 0.20mm。
- 前框前板仍是 1.2mm；唇 + 导框 + 四角耳共同提高前框抗弯，屏的玻璃和主板成为前框的“内支撑”，但**不把玻璃当结构压紧面**。

### 2.2 前装拆顺序（必须改变）

V1 是“前壳先放、主板从后装入”；屏唇内口小于玻璃，这个顺序会挡住屏。V2 改为**前壳最后盖上**：

1. 后板平放；装 PCB/显示、四颗 PCB 螺丝、电池、扬声器、候选线束。
2. 前壳从 **+Z** 方向下降。四个角耳在机身外侧，不扫过 PCB；导框/屏唇从玻璃前方越过；窗单边 0.20mm。
3. 左壁两片键弹片从上方滑过原厂开关外侧；名义径向 0.15mm，不能斜插。
4. 四颗 **M2×6** 从后方装入四角耳；交叉轻拧。屏唇不承压，只做前向限位。

检查做了 +2/4/6/10/20/40mm 离散直提：前壳对 723 原厂实体、后板、电池、扬声器、候选线束均无碰撞（`checks.json/front_loading_sweep`）。**这是离散检查，不是任意姿态证明。**

### 2.3 后盖：2.0mm 均匀板 + 内筋 + 四角压紧

- 后板主体由 1.2mm 改为 **2.0mm 均匀板**；外表面在 z=−12.35，内表面在 z=−10.35（与前面壳后端同一平面直接贴合，旧版的 0.2mm 止口台阶取消）。
- 自由区加 **1.2mm 高 × 1.2mm 宽**内筋：X=−14、X=8 两条纵向；Y=0 一条横向。位于 PCB 背面之后，和 PCB 座、电池、扬声器、线束都留空。
- 四颗原厂 PCB 螺丝仍从后方锁入原厂金属嵌件；后板的四个 PCB 座高 0.85mm，接触金属件背面。
- 新增四颗 **M2×6 自攻**（DIN 7981/ISO 7049，PA12 预钻 Ø1.7）锁入四角耳；耳在主体外 2.67mm，螺钉头 D3.8、沉孔 D4.2×1.0。
- 卡扣、接收座、撬槽、起撬缺口全部删除；后盖不再靠 0.30mm 搭接和 0.15mm 轴向游隙定位。

### 2.4 TF、BAT_PWR、扬声器出线、USB

- **TF**：取消左侧壁直通槽；左壁补回，卡完全在机内；维护时开后盖（先卸四颗壳螺丝 + 四颗 PCB 螺丝）。原 TF 槽位置的补墙体积 30.7mm³，见 `hidden_tf`。
- **BAT_PWR**：KEY1 改为 `rounded_rectangle` 直条，与 BOOT 同高 3.0mm、R0.5；原来绕 TF 的 L 形取消。KEY2/KEY3 不变。
- **扬声器出线**：围框缺口从 Y 中部移到 **−Y 底边**（y≈−32.4）；候选线束从下口进入，路径 34.06mm（< 用户确认的 40mm 线长）。**实际出线边/面仍需照片或测量**。
- **USB**：保持 13.2×7.3mm，不缩；后板在 USB 下方开缺口，前壳保留 0.85mm 下唇桥；插头下方保留名义 0.5mm。

### 2.6 紧固件/耗材（相对 V1 的增量）

- **4× M2.5×5 机螺丝**（头型与原厂位相同，Ø5.0×0.85；原 M2.5×4 只剩 2.0mm 牙合，不建议继续用）。
- **4× M2×6 自攻**（DIN 7981 / ISO 7049，头 Ø3.8×1.0；PA12 预钻 Ø1.7；四角耳）。
- **0.2mm 单面泡棉胶带** 约 1m（裁 1.0mm 宽贴屏唇下；可不贴，唇与玻璃名义 0.10mm 不接触）。
- 不新增卡扣、金属嵌件、延长线或胶粘结构；TF 不再外露。

> 100.94mm 是四角耳外缘；耳只在四个角，主体中段仍是 95.60mm。若用户坚持 95.60，只能退回“两耳 + 左缝舌片/胶”的方案，左缝压紧没有验证；不建议为省 5.3mm 牺牲一次成功。

## 4. 下单/打印建议

- **材料/工艺**：优先 MJF/SLS **PA12**，黑色；要求后板平面度 ≤0.2mm、前框平面度 ≤0.2mm。若第一版是 FDM，0.20mm 窗隙和 0.10mm 唇隙需要先打小样；FDM 建议把窗隙放到 0.3–0.4mm/side，唇隙放在 0.2mm，先打窗/唇局部试样。
- **摆放**：
  - 前壳：前脸朝下，屏唇/导框朝上；唇的 0.4mm 悬挑是台阶，不需要支撑。键弹片在左壁竖立，U 槽开口向上。
  - 后板：背面朝下，2.0mm 板贴平台；座、筋、电池槽朝上，不需要支撑。
- **攻牙**：M2 自攻进 PA12，预钻 1.7mm，低速、低扭矩；PA12 可反复拆装次数有限，建议先在两片耳上试拧。M2.5 机螺丝只进原厂金属嵌件，不要用自攻替代。
- **屏唇**：唇下贴 0.2mm 单面泡棉（1.0mm 宽）再合壳；没有泡棉时唇与玻璃名义 0.10mm 不接触。
- **不要**把屏唇当压屏面强行拧紧；四颗壳螺丝只负责把前壳压到后板，屏的前向限位由唇完成。

## 5. 待用户确认/实测

1. 第一版是 **什么工艺/材料**（MJF PA12？FDM？树脂？），这次是否同一家；这决定 0.20mm 窗隙和 1.7mm 预钻是否合适。
2. 扬声器线**从哪个边/面**出？请给装入前的照片或实测；“底部”我按 −Y 边实现了，但需要确认。
3. 第一版前面那个小孔是不是你钻的？MIC 实际端口在哪？装壳录音是否正常？V2 没有新增 MIC 孔，避免把未验证位置固化。
4. **1.29mm** 是“推到左上角后，另一侧的总间隙”，不是单边间隙？这与 V1 的 1.20mm 名义总游隙一致。
5. 100.94mm（含四角耳）× 77.86 × 13.55mm 是否接受；如果必须 95.60 宽，需要退回未证明的左缝舌片方案。
6. 你是否愿意把装配顺序改成“后板/主板先装、前壳最后盖”（前装拆）？这是屏唇能真正包住玻璃的前提。
7. USB 口保持 13.2×7.3mm 是否确认（你插线后已撤回“太大”判断）。
8. TF 完全隐藏、维护必须开后盖，是否可以接受。
9. **0.2mm 窗隙的最不利组合**：打印约 0.1 + 后板定位 0.15 + PCB 0.15 = 0.40，而窗隙只有 0.2。前装时先让前壳靠导框/屏唇对中，再拧四角；如果实际偏紧，不改玻璃，把 `screen_clearance_mm` 改为 0.3 重出。若第一版是 FDM，建议直接按 0.3–0.4 出窗隙。
