## 2. V2 结构决定

### 2.1 屏幕：从“自由窗口”改为“前向限位 + 圆角紧窗”

- 窗由官方 STEP 的**玻璃前面**导出：50.54×73.06、R2.0；不再用整块 DISPLAY 的工艺包络猜尺寸。
- 窗：**50.94×73.46、R2.2**，单边 **0.20mm**；总游隙 0.40mm（V1 为 1.20mm）。
- 屏唇：内口 **48.54×71.06、R1.0**，压住玻璃边缘 **1.00mm**；唇底面 z=**0.80**，玻璃前面 z=**0.70**，名义间隙 **0.10mm**；唇顶 z=**1.20**，屏相对唇顶凹 **0.50mm**。
  - 屏唇不是压屏结构：它只在 +Z 方向挡住玻璃，避免屏幕高出机身；不建议靠唇口给玻璃预压。
  - 唇下限位 0.10mm，可贴 **0.2mm 单面泡棉**（唇下 1.0mm 宽）；泡棉压缩后仍是软接触。没有泡棉时玻璃与唇不接触。
- 窗后加 **1.5mm 宽、2.0mm 高的内导框**（z −0.5…−2.5），从玻璃外侧导向显示模组；与模组单边 0.20mm。
- 前框前板仍是 1.2mm；唇 + 导框 + 四角耳共同提高前框抗弯，屏的玻璃和主板成为前框的“内支撑”，但**不把玻璃当结构压紧面**。

### 2.2 前装拆顺序（必须改变）

V1 是“前壳先放、主板从后装入”；屏唇内口小于玻璃，这个顺序会挡住屏。V2 改为**前壳最后盖上**：

1. 后板平放；装 PCB/显示、四颗 PCB 螺丝、电池、扬声器、候选线束。
2. 前壳从 **+Z** 方向下降。四个角耳在机身外侧，不扫过 PCB；导框/屏唇从玻璃前方越过；窗单边 0.20mm。
3. 左壁两片键弹片从上方滑过原厂开关外侧；名义径向 0.15mm，不能斜插。
4. 四颗 **M2×6** 从后方装入四角耳；交叉轻拧。屏唇不承压，只做前向限位。

检查做了 +2/4/6/10/20/40mm 离散直提：前壳对 723 原厂实体、后板、电池、扬声器、候选线束均无碰撞（`checks.json/front_loading_sweep`）。**这是离散检查，不是任意姿态证明。**

### 2.3 后盖：2.0mm 均匀板 + 内筋 + 四角压紧

- 后板主体由 1.2mm 改为 **2.0mm 均匀板**；外表面在 z=−12.35，内表面在 z=−10.35（与前面壳后端同一平面直接贴合，旧版的 0.2mm 止口台阶取消）。
- 自由区加 **1.2mm 高 × 1.2mm 宽**内筋：X=−14、X=8 两条纵向；Y=0 一条横向。位于 PCB 背面之后，和 PCB 座、电池、扬声器、线束都留空。
- 四颗原厂 PCB 螺丝仍从后方锁入原厂金属嵌件；后板的四个 PCB 座高 0.85mm，接触金属件背面。
- 新增四颗 **M2×6 自攻**（DIN 7981/ISO 7049，PA12 预钻 Ø1.7）锁入四角耳；耳在主体外 2.67mm，螺钉头 D3.8、沉孔 D4.2×1.0。
- 卡扣、接收座、撬槽、起撬缺口全部删除；后盖不再靠 0.30mm 搭接和 0.15mm 轴向游隙定位。

### 2.4 TF、BAT_PWR、扬声器出线、USB

- **TF**：取消左侧壁直通槽；左壁补回，卡完全在机内；维护时开后盖（先卸四颗壳螺丝 + 四颗 PCB 螺丝）。原 TF 槽位置的补墙体积 30.7mm³，见 `hidden_tf`。
- **BAT_PWR**：KEY1 改为 `rounded_rectangle` 直条，与 BOOT 同高 3.0mm、R0.5；原来绕 TF 的 L 形取消。KEY2/KEY3 不变。
- **扬声器出线**：围框缺口从 Y 中部移到 **+Y 底边**（y≈−12.4，靠电池/照片中音箱底部）；候选线束从该口进入，路径 **28.22mm**（< 用户确认的 40mm 线长）。V1 装壳出声正常；V2 扬声器腔/格栅/泡棉不变，只改出线口。
- **MIC**：V1 装壳录音正常；V1 打印件前面有孔，V2 按 V1 候选保留 **Ø1.5 @ (27.3, 1.395)**，不再说“没有孔”。实际孔位以照片/V1 实物为准。
- **USB**：保持 13.2×7.3mm，不缩；后板在 USB 下方开缺口，前壳保留 0.85mm 下唇桥；插头下方保留名义 0.5mm。

- **4× M2×6 自攻**（DIN 7981 / ISO 7049，头 Ø3.8×1.0；PA12 预钻 Ø1.7；四角耳）。
- **0.2mm 单面泡棉胶带** 约 1m（裁 1.0mm 宽贴屏唇下；可不贴，唇与玻璃名义 0.10mm 不接触）。
- 不新增卡扣、金属嵌件、延长线或胶粘结构；TF 不再外露。

## 4. 下单/打印建议

- **材料/工艺**：第一版已确认 **PA12**；优先继续 MJF/SLS PA12，黑色；要求后板平面度 ≤0.2mm、前框平面度 ≤0.2mm。若这次改 FDM，0.20mm 窗隙和 0.10mm 唇隙需要先打小样；FDM 建议把窗隙放到 0.3–0.4mm/side，唇隙放在 0.2mm，先打窗/唇局部试样。
- **摆放**：
  - 前壳：前脸朝下，屏唇/导框朝上；唇的 0.4mm 悬挑是台阶，不需要支撑。键弹片在左壁竖立，U 槽开口向上。
  - 后板：背面朝下，2.0mm 板贴平台；座、筋、电池槽朝上，不需要支撑。
- **攻牙**：M2 自攻进 PA12，预钻 1.7mm，低速、低扭矩；PA12 可反复拆装次数有限，建议先在两片耳上试拧。M2.5 机螺丝只进原厂金属嵌件，不要用自攻替代。
- **屏唇**：唇下贴 0.2mm 单面泡棉（1.0mm 宽）再合壳；没有泡棉时唇与玻璃名义 0.10mm 不接触。
- **不要**把屏唇当压屏面强行拧紧；四颗壳螺丝只负责把前壳压到后板，屏的前向限位由唇完成。

## 7. 2026-10-26 追问答复

### 7.1 打印误差 / 精度

V1 屏窗名义 = 玻璃 + 0.60/side，对边总游隙 **1.20mm**；你实测推到对角后另一侧 **1.29mm**，误差 **+0.09mm 总**（+0.045/side），约为 50.54mm 玻璃宽的 **0.09%**。对 PA12 单件打印来说，**尺寸精度很高**；这 1.29 不是打印失败，而是 V1 设计本来就留了 1.2mm。

后盖翘曲是**平面度**问题，和这个 0.09 的 XY 尺寸误差是两件事。

### 7.2 屏缝方案与容错

- 新窗：玻璃 **50.54×73.06 R2.0**，窗 **50.94×73.46 R2.2**，单边 **0.20mm**，总 0.40mm。
- 屏唇：向内包玻璃 **1.00mm**；唇底 **0.80**，玻璃前面 **0.70**，间隙 **0.10mm**；唇顶 1.20，屏相对唇顶凹 **0.50mm**。
- 可见缝：被唇口盖住，正常正面看不到 0.2 游隙；屏要在 1.0mm 包边里才可能露边。
- 容错：
  - 打印同工艺 0.045/side → 实际窗隙约 **0.245/side**；
  - 前装导框/屏唇 0.20 自对中；
  - 前壳定位 0.15 + PCB 0.15 是最不利堆叠；最不利约 **0.40**，所以装配时先对中再拧四角；
  - 如果实际紧，**不改玻璃**，把 `screen_clearance_mm` 改 **0.30** 重出；FDM 直接 0.30–0.40。
- 屏不会突出：唇顶比玻璃高 0.5mm，即使前框有 0.4mm 翘曲，玻璃仍在唇下。

### 7.3 只做右侧两耳 / 左侧 PCB 螺丝

**4 颗 PCB 螺丝只把 PCB 压到后盖，不接触前壳。** 它们在 x=±20.5、y=−27.1/32.9，位于显示屏下方；拧紧时力是“螺钉头 → 后盖 → 原厂金属嵌件 → PCB”，前壳不在受力链里。所以：

- 左侧**后盖**确实被这两颗 PCB 螺丝压住；
- 左侧**前壳/左缝**没有被压紧，只靠 0.15mm 定位、屏唇 0.1mm 间隙和导框；
- 只做右侧两耳，左缝在拆装/翘曲时可能张口；这是 V2 用四角耳的原因。
- 左侧 PCB 螺丝也不能加长去顶前壳——那会穿过显示屏。

可选：
1. **四角耳（当前）**：最稳；100.94mm 宽。
2. **右侧两耳 + 左侧滑入舌片/燕尾**：98.27mm 宽；左缝由舌片承受，右耳拉紧；这是新机构，需重新出图/检查，未验证，不建议第一次就上。
3. **只右侧两耳**：左缝不压紧，不建议。

### 7.4 右侧螺丝是自攻进塑料吗

是。四角耳用 **M2×6 自攻**（DIN 7981/ISO 7049，头 Ø3.8）直接进 PA12，预钻 **Ø1.7**，无金属嵌件；4 颗 PCB 螺丝仍是 **M2.5×5 机螺丝**，进原厂金属嵌件（牙合 3.0mm）。自攻在 PA12 可拆几次，但会磨损；要多次维护可换 M2 热熔嵌件，或用更低扭矩。不要用 M2.5 自攻去替代 PCB 机螺丝。

### 7.5 厚度为什么增加

| 项 | V1 | V2 | 增量 |
|---|---:|---:|---:|
| 前面最高点 | 玻璃/前框 0.70 | 屏唇顶 **1.20** | **+0.50** |
| 后盖外表面 | −11.35（最大点其实是 USB 下框 −11.67） | **−12.35** | 相对旧后盖 −1.00，相对旧最大点 **−0.68** |
| 后盖内面 | −10.15 | −10.35 | −0.20 |
| 后盖厚度 | 1.20 | **2.00** | +0.80 |
| 名义总厚 | 12.3695 | **13.55** | **+1.18** |

前唇 +0.50、后盖净外移 +0.68（因为 V1 的最大点已经被 USB 下框 −11.67 占掉），合计 +1.18。4 角耳只加宽，不加厚。

如果嫌厚，可降到 **1.8mm 后板 + 0.35mm 唇 ≈ 13.15mm**；但 2.0/0.5 对翘曲和屏唇更稳，我建议先按 13.55 打。

### 7.6 后盖翘起是打印问题吗

**两者都有**：

- V1 后板只有 **1.2mm**、无内筋、无边缘压紧，是主因；PA12 MJF 的大薄板残余应力/冷却会放大。
- V2：**2.0mm + 1.2mm 内筋 + 四角耳 4 螺丝 + 4 颗 PCB 螺丝（8 点）+ 前壳当夹具**；后板被强迫贴平。
- 打印要求：后板背面朝下、筋朝上；平面度 **≤0.2mm**；不要用四颗螺丝硬压一个翘 >0.5mm 的件（会预紧/局部鼓起）。
- 装配：四角交叉轻拧，分 2–3 次；先对中屏，再拧后盖；如果还翘，换打印供应商/工艺，不要只加扭矩。

### 7.7 音箱与录音

- **扬声器**：V1 装壳出声正常；V2 的扬声器腔、围框、格栅、泡棉/阻尼都不变，只把出线口从 Y 中部移到 **+Y 底边**（照片里靠电池的那条边），候选线长 **28.22mm** < 40mm。
- **MIC**：V1 装壳录音正常；V2 保留 V1 前面小孔候选 **Ø1.5 @ (27.3,1.395)**（探针 0）。屏唇/导框不在这个孔的前方；前装后请复测录音，若 V1 的实际孔位不同，按照片改。
- **V2 的屏唇/前装不会堵住这两个功能**，但最终以第二件实物装壳录音/出声为准。
