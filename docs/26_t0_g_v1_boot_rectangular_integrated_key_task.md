# G-V1 KEY2 (BOOT) 圆角矩形一体 PA12 按键局部改进（2026-10-17）

> **用户授权开发：只改 G-V1 的 KEY2/BOOT 一体式弹片外观与必要局部几何。KEY1/BAT_PWR 继续保留原 L 形，RESET 保持卡针孔。** 不回归独立键帽方案、不增设活动件、不改 E/旧 G/Pocket OS、不合并、不下单、不批准打印。原 PR #3 保持 Draft。开发基线为 `e805d38` 的 G-V1，`14fbb31` 是只追加 Gemini 独立审计的文档提交，不是新 CAD。

## 为什么要改

当前原生 LEFT 视图 `deliverables/t0-g-v1/LEFT.png` / `front_shell.step` 中 BOOT/KEY2 的弹性臂呈明显 L 形机械开槽，用户希望更像消费电子的**常规塑料按钮**。用户接受“按钮可短一些、高一些”，圆角矩形/近正方形均可，但**不要为了审美换回独立按键、内塞/外压配、后方切槽或复杂双层机构**。KEY1/BAT_PWR 靠 TF 卡槽，仍保留 L 形是用户已经接受的外观妥协。现有 PCB/前后壳/后盖双浅扣/M2.5/总厚度等基本结构保持。

## 优先候选（只有一条路线，先局部验证）

- 将 **KEY2/BOOT** 的外侧可见弹片轮廓改成**圆角长方形**，外观尽量接近普通细长侧键。初步考察可见外形**沿设备侧边约 10–12mm、正反方向高度约 2.5–3.5mm**，以局部真实几何可放入为准；用户接受在侧边长度受限时做较短、较高的矩形/近正方形**按压区**，但**不允许为缩短外观直接把有效弹性臂砍半**。如果只把自由端外观做方形而长弹性臂仍外露，应如实展示，不能虚称整颗键是独立的方形按钮。
- **仍与 FRONT 单体打印**：采用三边 U 槽、一端连接的可挠曲悬臂；尽可能保持现有有效弹性长度**约11mm**、标称片厚**1.2mm**、槽**约1mm**、根部真实过渡圆角**R0.5**、同一原生开关/止挡/凸点对位。按压位置为接近自由端的外露平面，**不是把整块机械弹片涂满使其刚度激增**。不得新增独立帽、弹簧、销钉、胶等零件。
- 最薄壁/余筋按用户工艺底线**≥0.8mm**，如新高度/槽切入相邻结构、改变挠曲刚度或形成过短根部，不得仅以“STEP 几何有效”判定可用；按压行程、根部应变和非玻璃止挡需同当前结构**直接对比**。设计位移 `1.4mm` 仅为 CAD 假定参考值，不能当成原厂开关真实触发行程。
- **KEY1/BAT_PWR 及其 TF 避让和 RESET 圆孔几何、整机外轮廓与12.4mm名义目标**保持不变。后盖、四 M2.5×4 普通机螺丝、低矮电池围框、扬声器暂定围框也保持；**除 BOOT 改造所迫不得已的局部让位外，不要动别的结构**。

## 唯一局部闸门（通过才完成整壳）

1. 基于原厂完整官方 STEP 的 **723 solids**，新 KEY2/BOOT 弹片与其内凸点静止、按压及释放的名义位置，**重新做完整屏幕+PCB 从 REAR 入壳 / 退出的连续扫掠**；保证不干涉原厂 LCD、TF、RESET、真实元器件/金属螺母。无需用夸大的独立碰撞测试集。
2. 新矩形按钮与原 L 型**同尺度**左侧原生 CAD 截图、局部剖面并排；明确短边/自由端应该按哪里，真实变形段留多长。检查大拇指/指腹常规按压时不会把力施加在固定根部而导致误解。
3. 检查 KEY2 不因改形状增加过度弹性应变、止挡前仍可触达开关、静止态不预压原厂开关。**原 `e805d38` 的 KEY1/KEY2 在 `register 0.20 + screw bore 0.15 + printed-tip -0.30` 组合下触达缺口0.054–0.056mm 仍是已知未关闭风险。不得通过删改失败工况伪造绿灯，也不默认按 Gemini 建议直接加长0.12mm。** 若新KEY2能以一处简单、双向验证的小改动获得正向收益，可报告；不要牵连改KEY1或静默宣布材料寿命通过。
4. 该方案若必须显著缩短11mm弹性臂、增加<0.8mm壁、和真实 PCB/TF 装配发生冲突、或需要复杂活动结构：**STOP**，只给最小妥协与前后尺寸/碰撞对比，用户可选择保留现有 L 型并进入V1实物阶段。不要展开多轮 A/B/C 工程探索。
