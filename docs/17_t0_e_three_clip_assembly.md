# T0 E：三点 PCB 止退 + 四浅窝 + 短齿整壳

本轮执行 [PR #3 的 E 收敛指令](https://github.com/Gadil123/esp32-design/pull/3#issuecomment-6216032701)。只采用一个机构组合：A 原有三个非共线 PCB 边缘弹性夹位、D 四个金属位外周浅窝，以及 D 式短卡齿/搭接段。没有新压条、插销、电子元件或 PCB 螺丝；不恢复 C1 的轴心刚性前环台。

**名义装入与 PCB 止退闸门通过后，完成 E 整壳。制造、侧键功能和真实有线拆装仍未通过，不批准打印。** 旧 A/B/C/D 交付、P0/P1 与 Pocket OS 保留；同一 Draft PR 等 Reviewer，不合并、不下单。

## 1. 谁承力，怎样放进去

坐标从官方原始 STEP 累计所有 occurrence 后绕 Z 180°，保持 **FRONT +Z、REAR −Z、USB +Y**；FRONT 看原生键/TF 在左。原始整板所有 723 solids 参与干涉检查，不拆显示模组，不从照片推孔位。

| 功能 | 本轮实际结构 |
|---|---|
| PCB 朝 FRONT +Z 止退 | A 原位置 **1 左上、2 右下、3 右上**三个 PCB 边缘夹位；接触 X≈−24.63/+24.62，Y≈+32.90/−27.11/+32.89。不是螺母轴心前台阶 |
| X/Y、朝 REAR −Z、背面支承 | D 四浅窝沿原厂金属安装件外周定位；E 承面−9.60，对金属后面−9.50留0.10轴向余量，作为后向辅助支承；A 夹位原有背托先限制 PCB 后移。中心 R1.6 不进螺纹孔，后盖内面−10.50 |
| 合壳与边缘定位 | 五处 D 式短齿/接收窗，搭接段辅助定位；接收壁/后盖壁在名义闭合处形成独立外围硬止挡，与 PCB 保持机构分开 |
| 禁止受力对象 | 显示玻璃、软包电池、开关/插座与其它电子元件均不作夹紧止挡 |

夹位保留 A 的 12mm 梁、1mm 厚度、0.8mm PCB 前挡片和 1.2mm 候选侧向让位。释放状态使用**根部固定、端部外移的几何代理**，不是把整根梁刚体瞬移出壳；连续 Z 装入以包含整个原板的扫掠包络核查，回弹则以实际止退/承托实体的侧向扫掠和梁包络对原厂 solids 检查。根部到自由端的 smoothstep 变形仅是可复现的让位姿态，不是计算得到的真实受力变形或工艺放行。

实际检查暴露并解决两项最小装配问题：

1. **A 原有避空不覆盖实际释放包络。** 特别是左侧原避空未向外完整延伸，且没有覆盖后承托/前止退片的全部高度和端部。E 只调整这三处前壳避空：向外1.4、Z −6.6至−2.9，并覆盖原夹位端部；不改夹位机构。A 默认参数/交付保持原样。左侧局部剩余外壁约0.9mm，必须列为 PA12 风险。
2. **键帽先放会挡显示玻璃。** 完整模组距到位6mm时，原三推杆各与显示玻璃有约0.08mm³真实交叠。采用唯一修正顺序：先装板、让夹位回弹，再从 REAR 放原有独立键帽；三帽后装的连续包络对前壳和原板检查无干涉。没有缩触头、重画 RESET 或假设开关行程。

## 2. 12.4mm 与三点限位

外形保持 **99.60×77.86mm**；两颗键帽外伸仍使横向总包络 **101.50mm**。玻璃/前框名义最高 Z=+0.70，后盖最低−11.70，包含原厂所有零件、两完整壳、键帽、临时配件/保护板、胶层/泡棉/阻尼、插头及线束包络，名义最大厚度 **12.400mm**，没有忽略局部凸起。

为避免 A 的0.1mm前向游隙允许玻璃浮出、把包络增至12.5，E 仅将该既有参数设为 **PCB 前止退名义间隙0.0**；相同0.8厚挡片下移0.1，距 LCD 由约0.1增至约 **0.2mm**。前片承力目标是 PCB，不夹玻璃；背面承托与金属浅窝形成相反方向的反力。

三点的接触坐标矩阵秩3；接触三角形面积约1477.6mm²。A 夹位自身前挡与背托的接触凸包重合，有正面积交叠；四金属位的布局凸包与其交叠约1227.1mm²。在**零前挡/背托游隙、刚体、理想尺寸**模型下，任何非零Z/俯仰/滚转都违反夹位的至少一个接触半空间，故不是靠两点、玻璃或电池防翘。报告另外用实际 PCB 的+0.4mm、绕X/Y各±0.5°姿态验证 PCB/金属接触反力，不拿碰撞到玻璃冒充有效止挡。

**合壳载荷不通过 PCB：** E 周边接收壁下端与后盖壁上端名义接触，四窝的承面退后0.1。额外诊断中让后盖向前0.05，外围壁已产生止挡交叠，而四窝仍不碰原板，证明名义结构有绕过 PCB 的合壳承力路径。四窝保持原外周0.8包覆高度，空腔深度增至0.9；不靠紧压金属件闭盖。原有三个 A 背托因此是第一后向支承，四窝是侧向定位和第二后向支承；没有把这一点写成四窝名义夹紧。实际尺寸链可能改变承力先后，仍须实物确认，不能强扣。

**零名义游隙不等于实物零公差配合。** PA12 和原板误差可能使装不进、产生不应有预压，或留下浮隙；三夹位释放、同时保持让位的操作/工具可达性、止退片强度、金属件与 PCB 受力均待实物验证。根部固定代理的简单应变估计约2.8%，A 原悬臂简化值约1.25%，两者边界条件不同，均不作为允许应变或寿命证明。不能把理想12.4mm推成制造后任意载荷下的保证。

## 3. 短齿与实际装拆顺序

五处是根据本机可用空间选择，**不是声称 Passport 有五个/七个相同卡扣**：

| 打开顺序 | 边缘 / FRONT 坐标 | 局部半长度 |
|---|---|---:|
| 1 | 下边 Y=−35.93，X=−15 | 8.0 |
| 2 | 右边 X=70.13，Y=−17 | 8.0 |
| 3 | 右边 X=70.13，Y=+26 | 8.0 |
| 4 | 上边 Y=41.93，X=−15 | 8.0 |
| 5 | 左边 X=−29.47，Y=+16.8 | 3.2 |

右侧分成上下两处避开保护板出线区；顶扣偏左避开 USB；左扣限长以避开 TF 和左上 PCB 夹位。局部连续搭接段在接口/配件区中断，未增加一条会挤压电池的全周环。搭接段端部退让0.2，避免与旧后盖壁角形成仅一条线相接的网格边；外侧后盖壁和底板仍连成单个实体。

保留 D 的1.5厚短壁、0.7齿突出、0.4保持重叠、1.5窗下承力段、0.3搭接间隙和0.5自由端让位代理。每处外部0.35厚撬片通道、扣入/退出扫掠、后拉0.3保持交叠、局部张缝2.8后回弹不复扣均在**最终整壳**复查。4.6mm短壁的约5.3%线性应变仍显著偏高；真实弯曲、扣入力、清粉、蠕变和疲劳 `UNVERIFIED`。

装配：三 PCB 夹位保持向外→完整板沿+Z放入→三夹回弹至 PCB 边→从背面放键帽→接线/整理已确认的配件→后盖四窝就位、逐处扣合。拆卸：从底部窗口退齿，手支承并保持已打开处约2.8局部张缝，依次右下/右上/顶部/左侧；取盖时不拽线。之后可先取键帽，再让开三 PCB 夹位，整板沿−Z取出。

报告区分非柔性后壳/附属电池包络的连续直线运动检查与卡齿局部代理。**没有用五扣同时平移，证明完整盖板可依次弯开。** 实际逐扣释放时，前扣能否保持张缝、邻扣与薄后盖如何弯曲仍待实物；这是完整名义 CAD 的功能门槛，不是已通过的实机装拆。
