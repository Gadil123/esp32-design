## 2. P0：用改变装配顺序优先破解 PCB X/Y + 侧键的 0.074mm 问题

**旧证据必须保留。** G 原方案「三键帽预装、四螺丝先把 PCB 锁后盖、模块从 REAR 沿 Z 整体推进」在键帽/LCD 区域仅有约 0.074/0.076/0.075mm 名义净空；Ø2.8 后盖过孔对 Ø2.5 螺杆允许径向浮动 0.15mm，**PCB 向键侧偏移 0.10mm 的实际原厂 LCD 碰撞反例**存在。不要仅靠缩孔或拧紧力宣称具有 0.074mm 精密定位。

**优先验证单一路线：** 前壳正面朝下放在柔软、干净的支撑垫上，保证玻璃全过程不会因前窗口贯通而掉出或被硬物顶压：

1. **不带独立键帽，把完整官方 LCD+PCB 从 REAR 沿 +Z 直线放入深前壳**，确认屏幕齐平、玻璃周边留有真正制造装配余量，PCB 不以玻璃承受装配夹紧力。
2. 从 REAR 把**仅剩的两颗 BOOT / BAT_PWR 键帽后装**，沿用 E 版已证实的“板先、帽后”思路，但必须在 **G 的深前壳真实几何中重新验证键帽手工可达、法兰保持、正常触发与拆出路径**。RESET 无活动键帽，避免原 0.5mm 薄面料。
3. 接妥可用的电源/扬声器线束并留合理拆卸余量；**后盖此时尚未上 PCB 螺丝**，从 REAR 沿直线压入、浅卡扣轻扣。对准四个原厂 M2.5 安装位，再从后盖外侧逐颗装入四颗机螺丝，将 PCB 固定于后盖承压座；拧紧不能“拉板找孔”、压玻璃或压电池。可研究少量宽松导向面辅助对位，但不要增加精密定位销/工装。
4. 拆卸反向：**前面朝下软垫承托 → 卸四颗 PCB 螺丝 → 用一张卡片逐个释放后盖 → 后装键帽从 REAR 取出 → 整板从 REAR 取出**。期间任何阶段都不能让裸 LCD/PCB 自由坠落或拉扯线束。

**这是优先验证的提案，不是已证明可行。** 特别检查以下实质约束：
- 当 PCB 尚未拧在后盖上，浅卡扣合盖是否会推走 PCB、让四孔无法对中？是否可在真实操作条件下让螺丝穿过 REAR、稳定咬上四个原厂金属孔？开口是否能容纳操作工具？不得把“螺丝自动找正”当成事实。
- **键帽已安装后**，PCB/前壳/后盖允许的最不利 X/Y 漂移能否保持键帽接触到原厂可动开关，且不顶到固定框？允许的公差与用户正常按压必须覆盖，不能因为“装板时没有键帽”就把所有 XY 风险删除。
- 卸螺丝、撬后盖时完整 PCB 是否被安全支承，尤其胶/泡棉或玻璃不可成为临时夹具？正常翻转使用时，锁紧与壳连接能否保持前向止退？
- 若两键后装、四孔对位、后盖压合或反向拆卸之一失败：**STOP**，用一张局部真实剖面和最小实物/尺寸原因说明。允许提出**一个**最简单的让步（如局部键帽导向避空、两键改成可从外侧拆卸、关键位置少量余量），量化是否需要 X/Y 宽度小幅增加；**不准自动发明复杂精准销钉、倾斜装板、第三套锁止机构**。

## 3. P0：后盖卡扣按“普通电池盖”使用体验收敛

- 首先用周缘**非锁定止口、少量闭合肩面**确定 REAR 位置，**锁止与定位职责分开**；两处浅扣只承担不自行脱落的保持力。若实际外形需要第 3 处，仅在说明必要性后添加，不恢复现有 4 处需同步外部释放的盲卡扣。
- 从真实截面说明卡扣**导入坡面、根部过渡圆角、打印最薄壁厚、能清粉的缝隙与卡片进入位置**。允许微量装配游隙，避免“零尺寸公差/四角全部预紧”的不可制造理想条件。
- **必须验证一张常见塑料卡片或塑料撬片能从单个开盖缺口开始，顺序逐扣解锁**。不需要四片 0.15mm 工具，也不许要求整体退 8.3mm 才放开工具。释放过程不得通过扭曲带玻璃的 PCB 或拉拽线束实现。
- 无需虚构扣合力 N、50 次寿命或精确材料弹性极限；以简单 CAD 连续路径及正确注明“材料/尺寸公差需首轮实测”为准。宁可 V1 稍松、V2 再增强，也不要第一次打印就因过紧断齿或难拆。

## 4. P1：常见固万基 M2.5×4 机螺丝为选型基准，先不加厚

用户给出的**商品图片为设计基准，尚非实物测量或订单确认**：

| 尺寸 | G-V1 候选 |
|---|---:|
| 类型 | **普通机螺丝（十字薄头，304 不锈钢），不是自攻** |
| 螺纹直径 / 螺距 | **M2.5 × 0.45mm 粗牙** |
| 螺杆长度（不含头） | **4.0mm** |
| 头部直径 | **约 5.0mm** |
| 头部厚度 | **约 0.85mm** |

从后盖外侧直通孔穿入原板的四处 M2.5 金属安装位；严禁使用购物图中的 M2.6×5、M2.3×4 自攻件损坏金属螺纹。螺丝头允许**齐平、浅沉或外露**，但要**先研究 12.4mm 主体且螺丝头齐平的简单沉孔**；没有制造理由不必先改为高一截的后盖。

可作为检查起点的**名义尺寸链**：原厂金属安装件背面 Z≈−9.50，REAR 外面 Z≈−11.70，轴向总差≈2.20；若 0.85mm 螺丝头齐平，则头部承压面≈−10.85，下面的 PA12 承座轴向厚度**理论约1.35mm**，4mm 螺杆进入金属安装件的名义长度约**2.65mm**。这两个数字**只在实际直通孔/沉孔/金属孔构型保持对应基准时成立**，并未考虑螺纹起牙、末端倒角、生产公差和可用螺纹深度。须以最终 3D CAD 剖面重测有效接触环面积、轴向啮合及扭矩/蠕变风险。

**只有当**实际 M2.5×4 的有效啮合深度、PA12 承座或沉孔工艺不足时，才给用户简明备选：局部加厚 REAR（注明最大总厚度）、螺头局部外露、或常见的其他适当长度**机螺丝**。不得自行加厚全盖或将螺丝头置入更深而削薄承压 PA12；不得现在为了想象问题采购小众 NBK 超低头。

## 5. P1/P2：其余低复杂度检查与 Gemini E 迁移要点

| 独立 E 审计指出的攻击面 | 本轮 G 如何处理（不抄其未经实测定量断言） |
|---|---|
| 短卡扣根部尖角、短梁弹性假设 | 卡扣改少/浅、圆角过渡、保证最薄壁与导入，让顺序拆卸在真实路径可行；不宣称 3.21% 或 5.32% 是寿命证明 |
| 三 PCB 弹性夹须同时手动撑开 | G 的 PCB 使用四 M2.5 固定，无须恢复 E 的三夹；新顺序单人可操作性仍必须成立 |
| 零轴向间隙导致夹玻璃 | 前后壳肩面/止口承力**绕开玻璃**；允许真实制造间隙，不能依赖裸玻璃做装配限位 |
| 撬盖倾斜与浅窝卡死 | G 不复用 E 四浅窝作金属柱配合锁定；但 PCB 拧在后盖上、拆盖卸螺丝后的可达性仍需验证 |
| 键帽后装、防掉落、原厂开关固定框 | 两颗日常帽后装路径、保持/触头重叠与按压回弹检查；RESET 去活动帽 |
| MIC1 被壳遮挡 | **录音是核心 V1 功能**：根据官方元件声孔方向和 STEP/实物证据决定是否补直接声孔，不得盲开；无法判定须醒目标 `MIC_AUDIO_PATH_BLOCKED_UNTIL_HARDWARE`，不要把无声孔整机宣称语音功能就绪 |
| USB-C 端口下缘薄、插头肩部不一定完全插入 | 保留实际原厂 USB 位置；检查常见真实插头肩台外包络/插入深度，任何截面 <0.8mm 需报告并作局部简单修改或向用户说明妥协 |
| 小缝隙清粉、定位导入 | 浅扣/止口/后盖开合处保留可打印配合间隙和简单倒角，不新增精密缝 |
| 电池保护板 0.23mm 局部净空、软包膨胀、线束拉扯 | 实物到货后复测；现有尺寸仍是临时包络，避免让卡扣/螺柱压电池、后盖夹线，预留必要走线余量 |
| TF 弹出/指甲空间、齐平玻璃抗磕碰 | 实用性标注/实机核验；用户**已主动选择**齐平，不为防摔擅加 0.3–0.5mm 护檐 |

其他：侧壁/RESET/USB 处局部 PA12 有效壁厚逐处核查；不把偶然 0.5mm 面层、0.25mm 原薄压边留在新实体里。原厂声孔、MX0/1 公插头/极性、电池/扬声器参数不得凭轻量代理猜测为已验证。

## 6. 有限验收、交付和 STOP

**先跑装配门槛，再改完整模型；只做这一个 G-V1。** 先以原厂全部 723 solids 和真实两壳/键帽 BRep 验证：（a）无键帽入板及两键后装；（b）后盖先扣、四螺丝后拧的真实可达/对位/反向拆卸；（c）PCB 与键帽最坏公差、独立前向/后向保持；（d）一张卡片能顺序拆扣；（e）USB/TF/RESET、临时电池/扬声器/线束不出现新的名义硬碰；（f）实际包括螺头的最高/最低尺寸（目标12.4），PA12局部薄壁清单。

**失败即 STOP**：报告一个可复现的真实碰撞或不能操作的步骤，以及一项最小设计妥协，交给用户选择；不要连造多套候选也不要默认改外形/加厚。

通过名义几何后，更新 `cad/t0/` 内 **G 自有参数/模型/检查**、`deliverables/t0-g/` 与 [19 G 实现记录](19_t0_g_recessed_assembly.md)（可以另加修订段，保持旧版本历史可追溯）；提供以下最小交付：
1. 完整原板对应的 **FRONT、REAR、LEFT、ISO** 原生同尺度 CAD（与冻结 E 对照），**齐平局部剖面**、四螺丝头/1.35承座/螺纹剖面、**先扣后锁/两键后装/卡片顺序拆卸**图。
2. G 单独 STEP/STL 和全量官方原板装配交付，回读有效实体、最大 Z 厚度和关键碰撞；配对的 `checks.json` 显示**已通过/失败/未验证**的各自证据，不把“能画 STEP”当成打印合格。
3. 一页 **G vs E**：外形一致性、12.4目标达成情况、E/G 固定差异、装配步数、残余制造风险；以及**最短购物清单**（机螺丝规格/长度4mm是否最终可买、仍需实物确认的配件）。
4. 只把 G 的修订推送 **原 Draft PR #3**；Reviewer 复审前保持 Draft，**不合并、不下单、不打印**；不改 E、Pocket OS，不添加大规模测试矩阵/通用 FEA、**不做 SHA 校验**。

**验收口径：** `G-V1 12.4mm nominal assembly gate PASS / material and physical-fit pending` 只有在对应真实 CAD 几何检验通过后才可使用；否则必须准确报告 `BLOCKED` 和最小让步。
