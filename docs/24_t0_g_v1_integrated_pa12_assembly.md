## 复现与文件

环境：Linux、Python 3.13.2、build123d 0.13.0、OCP 8.0.1.1.0；依赖版本沿用仓库 `requirements.lock.txt`。首次建立项目独立环境：

```bash
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock.txt
```

官方只读仓库与本仓库并列，要求存在 `../ESP32-C5-Touch-LCD-2.8/dimensions/ESP32-C5-Touch-LCD-2.8.stp`。缺少时：

```bash
git clone --depth 1 --filter=blob:none --sparse https://github.com/waveshareteam/ESP32-C5-Touch-LCD-2.8 ../ESP32-C5-Touch-LCD-2.8
git -C ../ESP32-C5-Touch-LCD-2.8 sparse-checkout set dimensions schematic
```

完整重建一条命令（每次从原始官方 STEP 导入，不依赖开发缓存）：

```bash
./scripts/generate-t0-g-v1.sh
```

命令退出0只表示研究导出完成；必须读取 `checks.json` 的状态。当前完整候选含 `BLOCKED_CONDITIONAL_PRINT_FIT`，不是工艺/功能通过。

只重建首要局部闸门：`./scripts/generate-t0-g-v1-integrated.sh`。主脚本先运行该闸门，实质几何失败时停止整壳导出。不会自动推送、下单或调用 GUI。源代码入口 `cad/t0/generate_t0_g_v1.py`；关键尺寸集中于 `t0-g-v1-integrated-keys.json` / `t0-g-v1-closure.json`，沿用 A/G 参数及官方测量。

独立前壳/后盖 STEP、封闭 STL、轻量 STEP/GLB 和全部图纸在 [G-V1 交付目录](../deliverables/t0-g-v1/README.md)。轻量模型使用原板基体/金属件与已标明的元件包络，**不能用于净空证明**。精确检查始终使用全部 723 个官方实体。

完整原板装配 STEP 不进入 Git；私有 Draft release `t0-cad-review-20261016-9ec1022` 新增 `t0-g-v1-review-complete.zip`，含完整装配与报告；`t0-g-v1-integrated-local-review.zip` 含局部原板装配及偏移见证。下载：

## 坐标、完整厚度与取舍

保持官方几何相对位置，累积 STEP occurrence 位置后统一绕 Z 旋转 180°：USB 朝 +Y，FRONT 为 +Z，REAR 为 −Z，原生侧键及 TF 在正面观察的 LEFT −X。图纸均标观察面。FRONT 框面与玻璃名义 Z=+0.700mm 齐平，窗口横向间隙 0.600mm，无覆盖玻璃的压边。主体及永久件 XY 为 99.60×77.86mm。

最终厚度、实体回读结果与含后盖游隙的刚体上界见下方自动生成的实测表。厚度计入完整官方总成、USB 底框局部凸出、后盖、螺头、临时配件及线束包络。

为了给两个浅扣保留正轴向间隙，同时控制刚体翘动包络，后盖主体相对原 −11.70mm 内缩 0.35mm 至 −11.35mm，板厚仍为 1.20mm。USB 底框独立保留 0.85mm web，最低点约 −11.66952mm。不是把 USB 凸起排除在厚度检查之外。

**刚体上界距离12.4mm仅约0.014mm，远小于通用打印尺寸公差。** 本报告只证明指定CAD接触/刚体包络未超限，不保证打印成品在制造偏差、受载或翘曲后仍满足12.4mm；不能据此批准整机打印。

**四处 PA12 螺头承座最终约 1.00mm，低于任务书起算的 1.35mm。** 这是后盖内缩的明确代价；未声称扭矩、蠕变和有效螺纹已通过。没有通过更深的局部头窝偷偷削薄承座。四颗候选均为普通 M2.5×4、螺距0.45、头径5.0、头高0.85；Ø2.8 通孔/Ø5.8 头窝，头面与后盖齐平，名义进入金属件3.0mm。真实头型、起牙、可用深度与扭矩必须核实，禁止按模型直接采购或换自攻件。

## 两颗一体侧键

KEY1=BAT_PWR、KEY2=BOOT；RESET 保留 Ø2.2mm 卡针孔，不做第三弹片。每颗侧键为前壳一体 U 形悬臂，无独立键帽。侧壁1.8mm，片厚1.2mm，根至按压区12mm（固定根1mm，有效11mm），槽1.0mm，真实根部过渡R0.5。凸点0.8×0.8mm，局部非玻璃止挡厚0.9、高1.0mm。

为了不挡玻璃装入，静止凸点保留至完整板屏连续装入包络约0.55mm间隙，止挡约0.523mm。弹片主体上移至 Z[−3.33,−1.33]，避免 TF/U 槽形成薄桥；TF 至槽及槽上前框剩余实体均约1.03mm。图纸是导出 STEP 的实际剖切，未用概念图确定孔位。

原厂静止键面的自由间隙约0.924–0.926mm。因此0.4mm只是候选弹片位移，**尚未接触开关**；壳体止挡的按压区参考位移为1.4mm，**不是原生开关行程**。采用根固定、端力梁的端部旋转，凸点沿 Y 预补偿0.5mm，未假设自由端保持零斜率。在 PCB +X0.15mm、凸点 X 端部缩短0.30mm的有限偏移见证下，仍与原厂开关外形接触；另查同一X偏移下Y±0.15mm两端。这个方框角点比Ø2.8/Ø2.5的0.15mm径向游隙更保守，但仍不是完整打印公差栈或实际触发证明。

**不能将上述0.15mm见证当作整机按键公差通过。** 后盖止口还允许0.20mm径向自由度，与螺孔合计可达0.35mm；完整报告另给 `combined_register_bore_print_reach` 和相应真实CAD图，把该位移与凸点缩短0.30mm叠加。若在壳体止挡处仍有正间隙，则该条件下无法接触原键，明确为 `BLOCKED_CONDITIONAL_PRINT_FIT`，不是“待测即可视为可靠”。这是名义装拆闸门之外的制造配合阻断；不继续搜索按钮方案或静默增加行程。只提出一个后续最小让步：待实测后按实际缺口微调同一凸点/非玻璃止挡，再重验完整板屏装拆；本轮未实施，不能靠挤压玻璃或未知开关行程补偿。

名义按压模型允许与静止开关 BRep 相交来表示候选接触，但不能据此证明开关内部运动。报告单列外侧面范围之外的固定框**代理**检查；官方单实体未揭示活动头/固定框真实边界。实际触发、按力、回弹、止挡是否在安全过行程内均为 `UNVERIFIED_UNTIL_HARDWARE`，不是已解决的过压保护。

小挠度梁根应变估计：0.4mm约0.595%，1.4mm约2.08%；止挡再超0.02mm的几何反例确实碰壳。上述数值不含根部应力集中、偏心扭转、非线性和打印各向异性；无材料许用值、力 N 或循环寿命声明。

## PCB 固定与装拆

完整723实体的总成从 REAR 沿 +Z 直线装入，沿 −Z 拆出；凸点、止挡、接收扣座均在真实前壳内参与检查，不需要同时把两片向外拨开。整板的连续扫掠采用保守 AABB 与真实前壳布尔求交，空交集才通过；不是三张离散姿态代替路径。

顺序：

1. FRONT 朝下放在干净柔软的工作支承上。未上螺丝的板屏总成没有开壳翻转保持，拿持时扶原厂金属安装件，不让玻璃或线束承受装配拉力。
2. 板屏直线装入，核对齐平与四安装位；接线按实际配件确认。无键帽后装步骤。
3. 后盖先轻扣，目视检查四孔，然后逐颗手工松拧入原厂金属螺纹。错位则重新打开对齐，不能靠拧螺丝硬拉板就位。CAD 只证明孔/工具可达，**没有证明盲操作四孔会自动找正**。
4. 正常闭合后的轴向链为螺头→PA12承座→原厂金属件；前壳有独立肩面和非锁定止口。玻璃、PCB板面、软包电池均不是合壳夹紧止挡。
5. 拆卸仍 FRONT 朝下软支承，先卸全部四螺丝；PCB 留在前壳。下方入口辅助手指抓盖，单张0.8mm三角塑料撬片经下扣 U 槽释放；下角拉开2.2mm，下扣可松回，再把**同一张**撬片移至上扣 U 槽，释放后抽出后盖。最后板屏直线取出。

两扣为右下/左上对角布置，弹梁长10mm、宽1.1mm、板厚1.2mm、槽1mm、R0.5根，浅齿轴向间隙0.15mm。各扣端部参考释放量0.5mm，力作用点位移约0.239mm，梁根估计约1.30%；未实测卡紧/拆卸力。单入口起盖后移动同一工具，不需四个保持片，也不需带玻璃模块保持退出8.3mm。

固定后盖分成覆盖全部体积的精确 CAD 单元，解析旋转包络覆盖下角首次抬起的所有角度；随后检查连续后退、下扣松回和未释放上扣。包含723原板实体、前壳与固定扬声器。1.1mm厚片进入1mm槽的负向测试必须碰撞；两个扣的后退保持探针必须碰到前壳。

后盖正游隙可能引起翘动。检查根据实际肩面、两扣接触区与完整外轮廓建立刚体平面约束，枚举倾斜符号求保守包络，计入接触区位置扩张/收缩和二阶修正。它是名义刚体约束，不是受载 PA12 弯曲、翘曲或制造公差认证。

## 接口、配件与未闭环项

USB 独立12.2×6.3mm插头体检查与开孔布尔分开；TF用独立11×1mm卡片沿 −X 外部取插空间检查；RESET以Ø0.8针只接近原厂KEY3、避开其他722实体。真实USB肩部、TF弹出方向/行程、RESET触发行程仍待实物。

电池34X×50Y×5、保护板、0.2胶层；扬声器30×20×6.8、含胶泡棉0.5、含胶阻尼0.3，均为 `unverified` 的临时包络。后盖移动时电池/胶/保护板随盖，扬声器暂按前壳泡棉固定；不据此证明实际胶接或安全固定。

MX0/MX1 开口朝−X、并非天然朝右舱。候选插头/Ø1.5线束仅证明**静态条件包络**；真实插头身份/极性/出口、端接、服务余量以及开盖时能否先拔插未确认。报告不能解释为带真实线束反复拆盖已通过。

**MIC1 是唯一麦克风，ES8311 是编解码器。** STEP未揭示进声口，声路仍标记 `MIC_AUDIO_PATH_BLOCKED_UNTIL_HARDWARE`，没有盲开声孔。需实物确认声口、线束避让，并比较裸板/装壳录音；几何无干涉不能证明收音不退化。

## 嘉立创 PA12 制造边界

[嘉立创官方设计指南](https://jlc3dp.com/help/article/3d-printing-design-guideline)的 MJF 建议包括局部10×10区域壁厚1.2mm、100×100整体结构约2mm、突起/卡扣建议大于1.5mm、装配间隙0.2–0.4mm、活动间隙0.6mm、100mm以下模型/孔公差约±0.3mm。具体黑色PA12承接与报价仍须供应商确认；不能把0.8mm细节分辨率视为结构合格。

本候选**不满足全部通用建议**：0.8mm凸点/扣座底/边缘台阶、约0.81mm释放处外壁、0.85mm USB web、0.9mm止挡、1.0mm承座、1.1/1.2mm弹片与0.15mm扣轴向间隙均需供应商专项接受。任务允许的≥0.8mm底线不是制造批准。U槽清粉、喷砂后尺寸、打印方向、根部回弹/蠕变与薄片保护必须确认。

[3D People PA12案例](https://www.3dpeople.uk/3dpeopleuk-blog/pocket-operator-case/)和[Triple Sine](https://triplesine.com/po-case/)仅支持一体尼龙按键的思路，不提供本机许用应变/寿命。没有采用 Gemini 未实测的断裂概率作为事实，没有新增 FEA、试样系列或其他竞争结构。
