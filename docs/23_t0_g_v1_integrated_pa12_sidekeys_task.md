# T0 G-V1：前壳一体式 PA12 弹性侧键——局部验证并继续完成整壳（2026-10-17）

> **开发授权：只针对 G-V1 按以下单一路线修改 CAD，先过局部真实装配闸门，再完成 G-V1 整壳。** 本任务是在 [21 G-V1 任务书](21_t0_g_v1_flush_easy_assembly_revision_brief.md) 基础上的**按键方案变更**，取代其中“两颗独立键帽后装”要求；[22 首闸门的 11.004mm³ 碰撞反例](22_t0_g_v1_first_gate_stop.md)作为历史证据保留，不删改。用户指定的 V1 优先级：**简单、可靠、方便频繁拆装、PA12 易打印，不追求按键手感或高频寿命**。E、旧 G 与 Pocket OS 全部冻结，不改、不合并、不打印、不下单。

## 0. 结构决策

**优先实现前壳一体打印的两处侧向弹性按压区（U 形悬臂 flexure，必要时仅在同一区域换成简单双臂/蝶形挠曲），不是独立键帽。** 在原厂 BAT_PWR（KEY1）与 BOOT（KEY2）位置，前壳侧壁切 U 形开缝形成保留一端根部连接的弹性片；内侧**一体成型简单按压凸点**对准原厂贴片开关活动面。外侧手指按压 → 弹片产生小幅可恢复弯曲 → 凸点压原生开关；不用额外 PCB、卡扣、键帽、弹簧、粘胶或精密装配工装。**RESET 不做弹片，保持卡针孔；局部实体壁厚≥0.8mm（优先1.0）。**

**来源与证据边界：** 参考 [3D People 的 PA12 SLS Pocket Operator 一体式按钮外壳案例](https://www.3dpeople.uk/3dpeopleuk-blog/pocket-operator-case/) 及 [Triple Sine 的 Pocket Operator Case](https://triplesine.com/po-case/) 所描述的尼龙粉末床打印弹性按键思路。案例不提供我们这个 1.8mm 侧壁、Waveshare 开关、嘉立创 MJF PA12 的具体许用尺寸/力/疲劳保证；AI Passport 的拆解照片也**尚不能证明其侧键与壳一体成型**，不得将参考产品当成 G 的功能验收。

## 1. 首要闸门：只做两键局部真实 CAD（失败立即 STOP）

沿用 [22](22_t0_g_v1_first_gate_stop.md) 的完整官方 STEP **723 solids**、前壳 G-V1 齐平基准、USB +Y、FRONT +Z、原厂键/TF 位于正面 LEFT −X。禁止以简化 proxy/图片代替与真实模组碰撞验证。

- **单一候选几何**：前壳主体侧壁保持约 **1.8mm**；尝试局部弹性片 **1.0–1.2mm**、有效弯曲长 **约8–12mm**、U 槽口宽 **约0.8–1.0mm**、根部有可打印的真实过渡圆角（优先约 R0.5mm 以上，按剩余净空修正）。这些是**建模起点，不是设计验收值**；局部任何薄弱处原则上**≥0.8mm**，且须考虑清粉、喷砂和打印公差，不能以 MJF 设备理论极限替代嘉立创实际承接标准。
- **静态与动态区分**：内凸点静止时不得持续按住原生 BAT_PWR/BOOT；候选按压行程可暂用既有 **0.4mm** 进行扫掠，但**开关真实行程、可动活动头与固定框边界未经实物证实**。不得把普通外包络接触当成实际可触发证明；没有开关内部运动资料则将功能明确标为 `UNVERIFIED_UNTIL_HARDWARE`。
- **最重要：重新检查板屏总成从 REAR 沿 +Z 直线装入/沿−Z 拆出**。真实一体弹片和**内凸点**必须包含在前壳实心实体中，不能复制旧“无独立键帽装板 PASS”作为新结构通过；检查显示玻璃、板边、原厂开关固定框和周边元件在整个路径的真实接触/干涉。若必须在装板时把一体弹片撬向外才能通过，需说明手工能否接近、所需变形是否安全，不得虚构随手可以同时拨两处。优先以触点形状或位置简单避让，不扩大整机。
- **防过压与疲劳最低限度验证**：按压到原厂开关实际触发行程之外的合理过行程，不能继续把所有载荷直接压给贴片开关；尽量由壳体非玻璃硬止挡限制总位移。检查根部尖角、有效臂长/厚度、估算弯曲应变及打印方向敏感性，明确模型估算不是寿命/受力实测。优先利用现有面与止挡，不新加复杂运动件。
- **稳定性检查**：不能因为两处侧面 U 开槽导致剩余支撑筋小于 0.8mm、USB/TF/RESET 处形成薄桥、开裂导向根部。两键间距和剩余侧壁连续性需真实几何报告。
- **放宽目标仅需报告，不自动实施**：如 1.0–1.2mm 片无法获得所需行程、造成 PCB 入壳碰撞、固定框受力或根部过高应变，**STOP**，给出真实碰撞/截面、最小妥协以及是否值得采用用户已认可的简单**后方开放导槽＋原帽**备选；**不要**再追加三、四种新按钮方案、复杂弹性铰链、微型活动卡爪或重画 PCB。

## 2. 通过闸门后继续原 G-V1，不再重启独立键帽探索

1. **屏幕齐平**（前框和玻璃名义 FRONT Z=+0.70），不覆盖原厂黑边；目标整机**含螺丝及永久件最大厚 12.4mm**，保持主体 XY 99.60×77.86mm（如必须改变，给用户列实际理由）。本次键改造**不得主动增加厚度**。局部超出 12.4mm 需要用户同意。
2. **四颗普通 M2.5×4 / 粗牙0.45 机螺丝**从 REAR 外侧穿孔拧入原厂四 M2.5 金属螺纹件；用户提供的固万基商品图片为头径约5.0、头高约0.85的**候选**，**不是已实测采购**；先试齐平头窝与约1.35mm PA12 承座的名义尺寸链，校核实际夹持面、孔位可达、有效啮合深度、扭矩与玻璃隔离；不使用自攻螺丝。
3. **装配顺序调整**：前壳正面朝下、柔软支撑且不压玻璃 → **屏幕/PCB 无任何独立键帽从 REAR 装入** → 接线/线束预留 → **后盖先轻扣定位** → 从 REAR 拧入四螺丝；拆卸反向。需要检查即使按键一体化也不能依靠拧螺丝硬拉 PCB 进座，正常使用时 PCB 的 +Z、−Z、XY 与绕 X/Y 转动限制有效且不过载玻璃。之前 **Ø2.8 过孔相对 M2.5 螺杆0.15径向游隙**仍需检验最终触点误差，而不是只因没有独立帽就宣布 XY 定位 P0 消失。
4. **后盖机构按 V1 原决策**：优先 2 个浅弹性扣 + 非锁定简单止口/导角，允许小量非功能性间隙；一张塑料卡片即可依次拆开，不需要四个保持片/8.3mm 保持距离。用户愿意在 V2/V3 调整过松的咬合，不接受 V1 过度锁紧导致拆坏；需验证按键一体片不随开盖受伤。
5. **RESET** 无活动键帽，仅卡针孔，局部壁≥0.8（优先1.0）；USB 实际插头肩部/边框最薄壁、TF 取卡、MIC1 声路等仍按 [21](21_t0_g_v1_flush_easy_assembly_revision_brief.md) 保留为真实待验证项。MIC 不可凭猜测乱开孔；电池/喇叭/线束是临时尺寸，明确实物验收门槛。
