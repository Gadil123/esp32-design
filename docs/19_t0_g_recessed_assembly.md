沿用 [T0 环境说明](11_cad_t0.md)：Linux、Python 3.13、独立 `.venv`，`requirements.lock.txt` 中的 build123d 0.13.0/OCP；官方仓库与本仓库并列且只读。

```bash
./scripts/setup-t0-reference.sh
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements.lock.txt
./scripts/generate-t0-g.sh
```

参数在 `cad/t0/t0-g-parameters.json`；沿用 A 的已确认板卡接口/配件临时参数及原三帽尺寸。G 独立模型、检查、图纸和入口分别为 `t0_g_model.py`、`t0_g_gate.py`、`t0_g_drawings.py`、`generate_t0_g.py`。复用已有几何函数，不改写 E。

小型文件见 [G 交付目录](../deliverables/t0-g/README.md)：两壳/三帽 STEP、STL，四螺钉外包络 STEP、轻量 STEP/GLB、原生 CAD 图纸、`checks.json`。轻量参考件有明确代理标签，**不用来证明干涉通过**。完整原板 STEP 在 `build/t0-g/assembly_complete_12_9mm.step`，压缩附件为 `t0-g-review-complete.zip`，放到 PR 使用的原私有草稿 Release，不把完整官方几何写进 Git。

候选采购件 **4 × NBK SSH-M2.5-4**：M2.5、螺杆4、头 Ø5×1.3，依据 [NBK 原尺寸表](https://www.nbk1560.com/images/en-US/product/lowsmallheadscrew/SSH/SSH_1.pdf)。后盖过孔 Ø2.8、头窝 Ø5.4。螺钉 CAD 为完整外部体积包络，不是精细螺纹/六角穴模型；工具以独立 Ø1.6 包络从 REAR 检查，只对该预期工具/头部配合豁免，不吞掉周边元件碰撞。不得用此候选件替代实板螺纹深度/实配扭矩测量。

每个头的有效承压环面积约13.477mm²，径向环宽1.1；名义螺杆伸入金属背面3.20、端部Z−6.30。只在螺钉检查中明确排除四个匹配的原厂内螺纹实体，其他原板 solids 全部保留；没有把预期螺纹啮合算成“零碰撞”。承座对原金属面有正面积接触探针证据，背面工具路径无名义碰撞。孔径/螺纹、低头强度、3.2是否全长有效啮合、拧紧扭矩、PA12压溃与蠕变仍 **UNVERIFIED**；厂家金属螺钉扭矩不能直接用于薄塑料座。

载荷链是 **螺头 → 后盖局部承座 → 原厂金属安装件**。四处非共线座承面限制相对Z/绕X/Y；四螺杆/过孔名义径向余量0.15限制横向浮动，夹紧摩擦不是已实测定位精度。螺钉只把板锁到后盖，不连接前壳。前壳四处独立肩面接触后盖，在原厂件后方保留空隙；额外+0.05闭合诊断已先触发外围肩面，玻璃距薄压边仍有0.20名义间隙。没有拿玻璃、PCB基体或电池承受前后壳夹紧力。

## 必须采用的装配顺序

1. 在打开的深前壳中放入原三帽，**整机 LEFT 朝下**。让三帽依靠重力落在导向的外侧硬限位：相对旧名义位置−X 0.30。PCB＋后盖随后沿 **+Z 水平直线**进入，拆卸沿−Z退出，仍保持 LEFT 朝下。
2. 在壳外将完整原板四个金属位与后盖座对正，四颗 M2.5 从 REAR 拧入；用开盖空间先接真实核准的连接器。临时电池胶层0.2、保护板、扬声器/阻尼和候选线束放在后盖组上，线束不靠拉插头张紧。
3. 整组直线送入。浅止口辅助XY导向，肩面决定闭合高度；四舌的端部让位后倒钩进入内壁盲槽。几何检查使用根部固定的让位形态及整个回位包络，不能当成实际扣入力预测。
4. 拆盖先从 REAR 左下边缘的一处起撬缺口开始，细片沿扣舌根部旁的槽进入，到自由端后再向内顶。逐处让位并保持四处释放；**四个外部保持片需要随模块退出至少8.3mm，再放松倒钩**。不让带玻璃的后盖局部剥起，不通过弯玻璃或拉线来先开一边。

**侧键是最紧的装配公差门槛。** 重现了旧名义帽位置在模组Z−6时三处与真实 LCD 约0.08mm³相交；外停靠后完整原板的连续包络距三帽分别约0.074/0.076/0.075。G 仅给 RESET 原帽后身增加0.3外移导向避空，因此正面维护孔后的局部面料由0.8减至 **0.5mm**，孔径仍沿用1.3、原帽与电子开关不变。停靠时 RESET 鼻仅内缩约0.05；隐藏维护防误触、细鼻、重力是否克服摩擦、向外限位是否可靠均需实物验证。不能把小于常见打印误差的净空解释成生产裕量；不将0.4候选帽运动当成未知开关真实行程。图/检查同时包含外停靠与0.4向内候选运动。

原厂 STEP 将每个 KEY 合并为单一实体，不能分辨真实运动件。[C 局部研究](15_t0_c_pa12_feasibility.md) 已记录固定框代理与偏心按压风险；G 沿用接触头和导向，不据“键帽对塑料壳的净空通过”关闭该风险。真实开关行程、框体、按偏时是否卡住及回弹仍需实物验证。

**这也不是已通过的定位容差设计。** Ø2.8后盖孔与Ø2.5杆允许0.15径向游隙，已经大于0.074玻璃余量，且头窝也允许该横移。检查另保留原板相对后盖朝−X偏0.10、装入Z−6的真实LCD碰撞反例；它仍在螺杆/头窝许可范围内。四螺钉的名义夹紧位置有可行路径，但不能保证任意拧紧位置都能装入；必须在拧紧前核对XY定位，是否可用简单工装可靠保持尚未验证。G本轮不擅自增设精密定位件或修改帽结构来宣称这一风险已解决。

量化下界：朝键侧的PCB/后盖定位误差必须小于约0.074，或在当前帽停靠基础上再让出至少约0.076，才仅能覆盖现有0.15孔隙并达到零碰撞边界，**尚未含外壳止口/扣槽配合游隙或任何工艺/实板误差余量**。后一数值也会进一步削弱RESET面料，不能作为已接受修正；这里只给Reviewer最小几何缺口，不继续搜索/实现别的结构。

## 四隐藏舌、盲槽和拆卸限制

四位在左右长边、FRONT Y=−28与+30附近，形成接近四角的矩形分布。它们避开左侧TF/三键和顶部USB，右侧避开保护板/扬声器及电池边界。没有复制E五齿位置/几何，也没有增加侧面接收通孔。

每舌根部Z−9.3，自由端−3.5，有效长5.8、厚0.8、宽5，倒钩高0.7、突出0.4，端部候选让位0.45。梁向腔内放置，在盲槽外保留约 **0.95mm** 壁，倒钩后向保持面与独立闭合肩面之间为**零名义轴向游隙**。原先0.1余隙会允许后盖后移，使厚度由12.9变成13.0，不能保留。现在增加后拉0.01的真实保持反例，并将允许的轴向游隙纳入最大厚度检查；另外从导出STEP的前后向微移接触取得两组接触凸包，核查秩3及正面积交叠，以约束刚体Z/俯仰/滚转；零间隙并不具备PA12制造公差保证。1.0高、0.6宽浅止口在电池上沿及保护板处中断，避免侵入软包/保护板；板卡限位不依靠止口或前压边。

报告保留负向保持证据：未释放向 REAR 拉0.3即与盲槽承面相交；让位后整段进入/退出无名义碰撞。**开缝1mm即回弹仍会卡住**，不是通过项；至少退到8.3后才可回弹。根部固定 smoothstep 姿态的简化应变约 **3.21%**，不是材料允许值、实际应力或五十次寿命。外部候选释放片的导入薄段0.15，末端与倒钩斜面相配；顺序检查先入槽、再内顶，不能用两动作的笛卡尔组合虚构“碰根部”。释放片是外部工具包络，不是新增产品零件。

**工具操作仍是未放行门槛：** 0.15薄片是否可取得、刚度/根部摩擦、同时保持四处且随后盖/原板平移8.3、实际扣入/释放力以及薄板翘曲未获实物证据。此处只证明有明确实体、接触/让位包络和连续路径，不声称一把普通撬片即可轻松拆机。若Reviewer认为这不够简单，应先收敛这一项，不擅自搜索新机构。

## 右舱、接口与检查范围

电池34×50×5、扬声器30×20×6.8、保护板/胶层/泡棉/阻尼均保持 **unverified** 参数。电池浅定位槽修整到深壳腔体内，上端浅止口中断；未缩电池，未加长机身。扬声器增加四处后盖支承垫，支在0.3阻尼下面，使其随模块进入前壳定位围框；正面0.5泡棉包含胶层，名义接触无压缩量；后方0.3阻尼总成也包含胶层，入壳前需将扬声器暂固定到四托垫，防止LEFT朝下时滑落或吊在线上。该粘接/侧向保持、最终泡棉压缩和实际出声口均待测。六条正面槽保留。

USB原生口和独立12.2×6.3插头通道保留；下薄边约0.880。TF保留−X外部11×1候选卡片通道，未伪造真实座入/弹出行程。MIC1不新增声孔，不能确认进声方向；ES8311仍仅是codec。右舱和线束不碰MIC实体，不代表其拾音声路已打通，裸板/装壳录音对照仍是V1门槛。
