## 1. 已知事实不能被「CAD PASS」自动关闭

1. **MIC 未实际开孔**：正面候选 Ø1.5mm，位置 `X27.30 / Y1.395`，只有几何空气路径；`MIC1` 实际封装进声口/PCB声孔仍 `UNVERIFIED`。PR #6 并没有把孔切入前壳。请明确判断：若 T1 目标包括装壳麦克风/语音验证，打印无孔前壳是否应判 **NO-GO**；如可通过独立钻孔或局部小样解决，请列为条件，不得假装已有麦克风功能。
2. **侧键触达反例保留**：不利组合下 BAT_PWR/BOOT 缺口分别约 `0.055722/0.053803mm`，`BLOCKED_CONDITIONAL_PRINT_FIT`，仍需实物打印触发/回弹验证。请判断此风险属于 T1 试打可接受，还是会导致「打印后无法有效验证按键」的阻断。
3. **MJF PA12 工艺限制**：有最薄外壁约 `0.81mm`、卡扣/凸点/承座的约 `0.8–1.2mm` 局部特征、`1.0mm` U 槽、`1.0mm` 螺丝承力座及其他敏感区域。不可因为 STL watertight / STEP 739 实体有效就宣称可制造；请重点检查孔槽清粉、尺寸一致性、壁厚及打印方向对卡扣和一体式按键的影响。
4. **扬声器围框—接收座**：右侧缩宽4mm并将整套扬声器结构 X−1.5mm 后，名义距离 `0.83mm`；各采用 `0.30mm` 候选偏差后的残余仅 `0.23mm`。检查双侧真实制造/定位偏差是否可接受，不能只引用无碰撞结论。
5. **锁扣与受力**：止退实际搭接 `0.30mm`、轴向游隙 `0.15mm`，下扣梁和承力桥虽然与冻结结构相同，但整体面板及格栅周围的韧带变窄。需排查首次装入/拆开时断裂、无法退齿、意外脱扣或变形导致装不上。不得用名义截面相同直接等同强度不变。
6. **四 M2.5 螺丝/实际件**：名义啮合约 `3.0mm`，承力 PA12 座约 `1.0mm`；确认螺头沉孔、螺丝长度、真实金属安装件、工具到达和受力路径合理，不能用胶水或玻璃承载来补足设计缺陷。
7. **实物配件及余量**：用户确认电池完整组件 `29.49×42.26×7.61mm`，不存在额外叠加的保护板厚度。电池上方原始净空1.84mm，扣1mm候选膨胀+0.3mm Z预算后余0.54mm；仍须避免压迫/夹线。扬声器 `30×20×6.5mm`，线长约40mm，用户已实摆认为够长；新CAD的37.02mm路径不是实际末端和开盖余量证明。扬声器围框泡棉、支撑高度 +0.3mm、出线与释放路径要核查。
8. **外部接口/装配**：USB-C、TF卡、RESET维护孔、装板取板路径、后盖卡扣撬片、全部四螺丝及隐藏的装配顺序；优先寻找 CAD 现有检查不能识别的「先装A才能装B、但装B又挡住A」问题。注意屏幕玻璃齐平、不得让它成为夹紧承力件。

## 2. 审查方法：独立挑刺，但控制成本

- **必须**实际打开/分析待打印壳体 STEP/STL 和关键截面，至少独立复核与 T1 直接相关的薄壁、卡扣、扬声器围框间隙、孔槽及安装件。若无法执行 CAD，则清楚标记「只做报告/代码审查」，禁止宣称独立几何通过。
- 阅读 `checks.json`，抽查假设、坐标、输入及遗漏；不必重复开发一套 CAD 引擎，不搞高成本仿真/完整 FEA，不要求重复作者的全部723实体逐面检查。
- 不得以不切实际的量产级验证门槛阻止**一次 T1 试打印**。应区分：打印前必须解决的致命问题、打印前可与厂商确认的工艺问题、以及必须通过 T1 实物才能检验的问题。
- 不为了得到 PASS 而删除失败测试、提高公差、改变目标或跳过真实功能口。
- **只做审查**：不修改候选 STEP/STL、CAD 源码、冻结按键或固件，不直接合并、发单、授权打印，也不做 SHA 校验。发现实质问题，提出尽可能小的定位修改；未经用户同意不实施。

## 3. 必须给出可执行的打印决策

报告开头用下列三种结论之一（仅针对**T1 首次工程试打印**，不是成品认证）：

- **GO (T1)**：现有文件可发厂试打印；风险基本只能靠实物验证，列明下单所需具体选项。
- **CONDITIONAL GO (T1)**：列出明确、可在下单前快速完成的条件（例如必须建 MIC 孔、必须经厂商确认某处工艺），条件未满足前**不得按 GO 执行**。
- **NO-GO (T1)**：有明确结构或制造阻断，直接打印极易造成无法装配、无法完成 T1 主要验收或整壳报废；指出证据与最小修复方向。

请回答五件事：

1. **现在发单究竟行不行？** 现有两个 STL / STEP 是否应直接交打印厂？
2. 哪些是**下单前 P0**，每条列出模型具体位置/数值、风险、证据文件及修复或补测方法？
3. 哪些是**可以留到 T1 实物验收**的项目？说明出现什么现象才需第二次打印。
4. 是否存在**方案只适合 MJF PA12 之外某种工艺**，或 MJF 打印方向、清粉、精度、后处理方面特别容易踩坑的位置？区分有来源的厂商要求和个人工程推断。
5. 给出一份**最短 T1 下单说明 + 到货验收顺序**，不要扩展到量产或大规模设计优化。

报告只需一份简洁中文审查意见：**结论 → P0 阻断清单 → 可接受条件/厂商问题 → T1 验收清单 → 证据引用**。若证据不足，请写 `UNVERIFIED`，不要凭猜测替作者背书。
