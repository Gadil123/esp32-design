# T0 C：四安装位装配闸门未通过，局部备用与 PA12 小样

本轮执行 [任务书](14_t0_pa12_simple_assembly_task.md)，没有覆盖 A/B、P0/P1 或 Pocket OS。**四个固定前侧支承台阶 + 后盖四定位窝的方案，最终静态放得下，但预定直线装入路径不成立。** 因此按任务书阶段闸门停止整壳重写，交付实际 CAD 碰撞证据、两颗原厂 M2.5 安装位的局部备用、USB 局部加强和独立 PA12 小样。这里不是已完成、可装配或可打印的 C 整壳。

## 1. 四安装位：真正的问题是装入，而不只是剩余厚度

从官方原始 STEP 累计 occurrence 位姿后，仍绕 Z 180°，USB +Y 朝上、屏幕 FRONT +Z、REAR −Z。四金属件标签为 `SMTSO-M2_5-4ET`，不是空着的四个裸 PCB 孔。

| 索引 | 真实轴线 X/Y mm | 金属件最低/最高 Z mm | 后盖内面到金属件最低面 |
| --- | --- | --- | --- |
| 0 左下 | −20.56818 / −27.10044 | −9.500 / −4.000 | 约 1.000mm |
| 1 左上 | −20.56045 / +32.89956 | 同上 | 同上 |
| 2 右下 | +20.43182 / −27.10572 | 同上 | 同上 |
| 3 右上 | +20.43955 / +32.89428 | 同上 | 同上 |

金属主体外径 5.50mm，进入 PCB 的颈部外径约 4.19mm；不能把“PCB 孔径”误当成可以插大塑料柱的空孔。STEP 的内孔/螺纹区域及后侧工具接近在报告中按真实几何量测；前侧通道被显示模组挡住，不能假定能从屏幕面拧螺丝。没有打印销紧塞 M2.5 内螺纹，也没有钻 PCB。

试验结构：后盖内面 Z=−10.50；环形承座接触金属件后端平面 Z≈−9.50，中央 R1.60 避空不进螺孔。外周窝包住后端约 0.80mm，其中最底部约 0.2mm 有原厂倒角，真正直圆柱配合段更短。壁厚 1.50。两个左侧基准每侧 0.10 间隙，左上沿 Y 放宽 0.30；右侧两处每侧 0.30 避空。这样避免四窝同时紧配；这些数值仍是待试样调整的候选，PA12 ±0.3mm 参考误差可能使 0.1mm 配合失败，不能强推主板入窝。

前侧用四个固定环台及侧向短臂：PCB 前面留 0.15mm 名义轴向游隙，环台厚 0.75mm，距原厂 LCD 约 0.10mm。最终位置不碰原板；受力目标是 PCB/金属件，不是触摸玻璃。两处左基准的 X 游隙约 0.10mm，仍会消耗原侧键约 0.15mm 的静态接触间隙；即使没有装入障碍，也必须实测配合和预压，不能把辅助胶当作补救保证。

**失败证据：** 屏幕已经与 PCB 组装，玻璃/显示模组平面投影覆盖四个环台。从 REAR 沿 +Z 放入时，距到位 4mm 和 2mm 均与环台真实实体相交；距到位 2mm 时，每处约 **23.6～23.9mm³**。最终位姿零碰撞并不能让它穿过中间障碍。从 FRONT 反向直线装入也需让原厂 PCB/金属安装件穿过环台，报告另外记录反例。删除前侧限位只剩后端支承，会丢失前向 Z 约束；靠触摸玻璃或胶止住都不符合任务。

此结论仅否定**本轮简单刚性台阶及直线装配顺序**，不是证明任何倾斜或其它四位定位结构都绝对不可能。复杂倾斜路径、拆原厂屏幕、重新引入四弹性夹位均未被当作解决方案。`C1_four_mount_static_BLOCKED.step` 和 `mount_assembly_sections.png` 是证据模型，不是打印件。

## 2. 两颗 M2.5 局部备用：可研究后盖固定，未直接改成主方案

原厂螺孔从后方可接近，因此比较索引 0/3 的对角两颗 M2.5。参考 [NBK SSH 官方尺寸表](https://www.nbk1560.com/images/en-US/product/lowsmallheadscrew/SSH/SSH_1.pdf)：M2.5、头 Ø5×1.3、候选长度 4mm。**这是可核对的低头候选，不是已经识别或采购了原厂随附螺丝。** 不能拿常见更高头型替换后继续沿用厚度结论。

| 参数 | 局部备用候选 |
| --- | ---: |
| 外部最低面/上限 | −11.70 / +0.70mm，12.40mm |
| 头底/头下承座面 | −11.60 / −10.30mm |
| 相对后盖外面凹入 | 0.10mm |
| 支承金属件后端 | −9.50mm |
| **头下打印承力厚度** | **约 0.80mm，MANUFACTURING_RISK** |
| 螺杆末端 | −6.30mm，未伸出 PCB 正面 |
| 名义进入金属安装件长度 | 约 3.20mm；实际有效牙数/扭矩未确认 |

力经螺钉头→后盖局部承座→原厂金属安装件，不夹紧玻璃或软包电池。孔/头窝候选 Ø2.8/5.4，前方保留安装件外周定位。杆部是公称外径包络，和内螺纹的预期啮合体积不能伪装成“所有零件零交叠”；没有精细模拟旋合与材料强度。

优先固定前壳的目标在这个简单刚性台阶方案中受装入障碍限制；本轮**明确展示后盖固定的局部对照**，没有擅自接受它作为最终 C。若另加后装的前壳压条，必须再解决压条、螺钉头和 1mm 余量的叠层，不凭空声称已可行。

备用顺序是先把 PCB 放到后盖四窝中、两颗低头 M2.5 固定，再使前框从屏幕正面方向就位；这与首选的“前壳先放板”不同。PCB 随后盖移动，拆盖必须支承两半，避免玻璃擦框、侧键拖拽及线束受拉；真实线长/接头方向未到货，整机有线拆装未验证。`C2_two_native_M2_5_REAR_local_ONLY.step` 仅是 PCB/显示/安装件及局部后盖块，不是完成了前后壳。

12.4mm 没有放宽。约 0.8mm 承座小于通用凸起/紧固结构建议，需要厂商审核和局部试样；不批准它承受锁紧载荷。**本轮仍没有可放行的整机方案。**

## 3. 四卡扣和开盖：局部证据与整壳验证分开

目标位置取现 A 中四处已有实际几何：底部 X=26、右侧 Y=−17、顶部 X=26、左侧 Y=+28（FRONT、USB 朝上）。保留上下/左右约束的概念，去掉其它三个扣位的整壳尚未重建，因为 PCB 固定闸门已失败。位置图是局部方案，不是四卡扣整壳已通过。

局部底扣样件增加一处约 5.2mm 长、0.8mm 深的撬片入口，接收窗与其相邻；试验塑料片厚 0.5mm，按进入→沿接缝到接收窗→推钩向内约 0.8mm 的路径检查。单扣释放后，需局部后退约 **3mm** 才能让钩回弹而不重新落入接收窗；0.5/0.8mm 的张缝不能冒充已防回扣。

建议动作图为底→右→顶→左，手托住已开的后盖边缘，再移动同一撬片。报告仅检查工具和**单扣保持 3mm 局部间隙**的姿态；没有把四个扣同时瞬移到释放位置，也没有证明完整薄盖能在剩余扣仍咬合时维持这些间隙。整壳顺序释放、长边翘曲、梁应变/疲劳仍 `UNVERIFIED`。卡扣小样用于先验证这个动作，不需要复杂 FEA，也不由局部试验替代整机装配。

## 4. USB、RESET 与侧键

USB 保留原 13.2×7.3 开口与独立 12.2×6.3 包胶插头探针，不缩孔、不加厚整机。在接口两侧增加局部圆角平面短筋，中心 (±7.8,39.8)，各约 2×4mm、角半径 0.6、顶面 Z=−8.0，向后盖内面连接；不挤入插头通道。**下沿最薄约 0.880mm 并未增加**，两侧筋只能作为分散载荷候选，不能证明薄边强度；仍标 `MANUFACTURING_RISK`。没有为了做孔角处理填小原矩形通道。单独局部 CAD/图纸供 Reviewer 审查。

RESET 孔样为 Ø2.0/2.2/2.5 三件，初始比较 Ø2.2，外侧都是圆孔；背面有开放避空，保留约 0.8mm 面部材料，便于核对收缩及清粉。独立推杆候选把按压面凹入 1.0mm，使用主体端面而非 A 的 Ø0.7 短圆鼻，保持不外露；可以从后方装入局部试验导向。不是修改 A，也不是承诺大孔不会误操作。工具可达、孔缩和实际按压由小样验证。

外露帽仍 4.6×2.2、暂保留 1.9mm 外凸。三组局部导向每侧 0.2/0.3/0.4mm，共用一个帽，减少重复打印。法兰候选前移到面后 1.4、额外轴向避空每侧 0.15，其余 0.4mm 仅为候选帽运动预算，不是实装开关行程。

官方 KEY 模型是单个融合实体，无法可靠拆出真实活动件。因此对“向外活动面投影以外的实际 source 几何”建立**固定框体代理**，检查居中/横移/倾斜应力姿态、0/0.15/0.4mm 候选推进的碰撞/接近。排除的投影区域不是已确认活动件；静态活动面处几何重叠也不是触发成功率。本轮实际在若干偏移、推进 0.4mm 的姿态检出约 0.046～0.055mm³ 的代理交叠，同时活动面仍有正重叠，状态为 `FRAME_PROXY_COLLISION_RISK`。这不是已拆出真实固定框的最终失效证明，但足以阻止把面积正值当成功能通过。小样先做**脱离原板的空载滑动试验**，未核实固定框/活动件和实际行程前不得在主板上强压。即便将来代理无碰撞，也只提供局部证据，实际固定框、回弹、接触力和行程必须实板验证；若存在碰撞，则直接保留风险，不用接触面积正值掩盖。

## 5. PA12 资料、小样与停止点

按用户指定黑色 PA12 MJF 研究。[嘉立创工艺页](https://www.jlc-3dp.cn/model) 将 PA12 列于 MJF；任务书的 [59512 材料文章](https://www.jlc-3dp.cn/technicalColumnsDetails/59512.html) 明确描述 SLS，其参数不能直接转成 MJF 订单保证。采用 [通用设计规范](https://www.jlc-3dp.cn/technicalColumnsDetails/27832.html) 的凸起/卡扣推荐 >1.5mm、100mm 内尼龙典型 ±0.3mm 和孔缩作为风险参考；这不是所有 <1.5mm 细节一律报废的硬判据，也不是订单已接受。

当前 1.2 后盖、1.0 卡扣梁、0.75 前环台、0.8 备用承座/RESET 面部、1.2 接触头、0.9 格栅槽及约 1.1 格栅筋均单列审核。原保护板右侧 0.23mm / 底面 0.20mm 净空保持临时包络风险，没有为紧凑需求假装消除 PA12 误差。到货后先调整保护板朝向/局部避空；如仍不足，再报告必要宽度，不强迫装配。

所有 `coupons/*.stl` **一文件一实体**，独立 STEP 同时提供，导出统一 mm 并移到各自最小坐标约 (1,1,1)mm 的非负位置（仅平移，不增加实体），变换记录在 `checks.json`。文件没有连杆、没有组合报价用多实体。样件分组：

- 卡扣接收窗/入口、卡扣后梁：2 件。
- 原厂金属安装件外周定位窝：1 件；不试紧塞螺纹孔，禁止拿 PCB 强压试配。
- 三组前/后导向：6 件，共用外露帽 1 件。
- RESET 三孔样：3 件；内凹推杆候选另 1 件。

共 14 个独立 STL，**只交付供审核/询价，不下单或批准打印**。前/后导向用外侧平面及侧边作装夹基准，按上下文 STEP 对齐；保留 0.15mm 原接缝间隔并记录夹紧方式/塞尺，否则误差会污染配合结论。先用一个帽逐组试，记录尺寸、自由滑动、回弹、清粉和按压位置；只有真实料号/开关和材料件才能关闭这些门槛。辅助胶不是当前结构的唯一约束，本轮未建模胶点；若将来使用，仅允许壳体安全区、由用户在实物验证后决定，避开电池、玻璃、连接器、MIC、天线、焊点及键帽，不封死维修通道。
