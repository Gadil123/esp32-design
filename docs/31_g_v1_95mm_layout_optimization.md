# G-V1 95.60mm 扩展仓布局优化

2026-10-20。**结论：CONDITIONAL——完整名义几何和装拆闸门通过，实物/PA12制造仍待验证。** 得到95.60 × 77.86 × 12.369521mm候选，宽度比冻结版减少4mm（约4.02%），长度和名义最大厚度保持。不是打印批准，也不宣称整体强度、真实线束服务或收音已通过。

机械唯一基线仍为 `ee8ec9d`，依据报告24/27/29及 [PR #5 / 到货评估30](https://github.com/Gadil123/esp32-design/blob/codex/gv1-hardware-local-revision/docs/30_g_v1_hardware_arrival_space_and_mic_assessment.md)。新模型独立输出，冻结前后壳、E、Pocket OS及固件不改。

## 本轮新增事实覆盖旧假设

- 电池 **29.49X × 42.26Y × 7.61Zmm为用户确认的完整组件尺寸**。不再另加保护板厚度。胶、膨胀、制造/安装及线束空间仍需保留。
- 扬声器主体30×20×6.5mm、线约40mm，用户已实摆确认线长足够；旧79.46mm条件路线不再作为布线不可行的证据。
- 用户进一步确认：**扬声器接板卡下端两针座**，对应USB+Y/FRONT+Z坐标中的 **MX1，Y≈−19.48mm**。上口MX0向电池的分配仍需核对丝印/极性和真实插头；不通过猜极性完成电气验收。

## 小范围搜索与最终选择

先截取冻结壳真实围框/接收座和原厂实体做局部搜索，然后重建整壳；没有只平移一个座就判定4mm不可行。

| 接收座X−4、扬声器/围框X−1.5 | 交体积0，净距0.83mm，原板无碰撞 | 最终采用 |
| 接收座X−4、扬声器/围框X−3 | 交体积0，净距2.33mm | 曾完成整壳检查，但侧向线束需改从围框下方绕行；最终选择较简单的X−1.5侧向走线 |

第一次X−3整壳未通过：侧向线束穿围框15.430768mm³，电池XY裕量包络穿旧浅槽圆角0.247221mm³；见 `iteration_a_failure.json`。没有豁免这两项：先用下绕路径取得名义通过（`iteration_b_result.json`），再采用X−1.5平衡布局释放侧向线束空间，并将电池浅槽间隙增加至0.75mm。失败记录保留，最终全部检查重新运行。

最终修改仅为：右侧壳边/止口/两右肩面/下扣梁及接收座整体X−4；扬声器、完整围框、原六槽格栅、泡棉/阻尼和四承托块整体X−1.5；完整电池中心X−2，浅槽按实测尺寸调整。Y布局不变，没有新增零件、开关或电子部件。

### 原17.1252mm³干涉如何解决

旧接收座X65.83…67.43，直接X−4后为61.83…63.43；旧扬声器围框右边至62.50，产生冲突。将**完整扬声器系统**X−1.5后，围框右边为61.00，得到0.83mm净距（冻结原版此处为3.33mm，缩宽后重新分配空隙）。围框壁仍1mm、对扬声器单边间隙仍0.5mm，没有削薄/削断冲突处。

再给围框与座各留0.30mm候选尺寸偏差预算，剩余0.23mm，大于本次采用的0.20mm残余目标。这是条件预算，不代表厂家已经承诺±0.30mm或接受当前薄特征。

## 电池、扬声器、声路及布线

电池完整组件中心X46.4/Y14.5；胶层候选0.2mm，主体Z−9.95…−2.34，前板内表面−0.50，净空1.84mm。向FRONT预留1mm膨胀候选＋0.3mm Z公差预算后，仍有**0.54mm**；不叠加虚构保护板，不允许靠软包压缩闭盖。XY每侧0.5mm尺寸加位置包络也对真实壳体、板卡、扬声器和线束检查；扩大后的电池包络在连续抬盖/后退路径同样无碰撞。

浅槽单边间隙从0.5加到0.75mm，使上述矩形裕量包络避开槽内圆角；壁厚/高度各1mm不变。使用适合电池的绝缘胶候选固定，不能只靠大间隙托盘宣称已抗滑移。胶材、真实膨胀、出线和粘接保持力仍要实物确认。

扬声器前缘泡棉/格栅仍同心平移，泡棉接触面积不减；四后撑随扬声器移位并升高0.3mm，填补PR #5发现的承托空隙。围框原有出线缺口保留；缓冲压缩量、实际端子和出声孔尚待确认，不宣称气密音腔或隔音达标。

MIC保留原FRONT Ø1.5候选位置X27.30/Y1.395与通往封装外侧的空气间隙，三个Ø0.5探针及孔切削候选均无非预期干涉。实际芯片声口/PCB声学通孔仍UNVERIFIED，未盲开孔、未加长声道；必须装壳对比裸板收音。

下口MX1的候选线束沿侧向间隙进入原围框缺口：Ø1.5包络、R1.5弯曲半径保持；侧向中心X26.635，玻璃投影与围框之间名义各约0.615mm。真实圆角中心线至暂存端约**37.0218mm**。末端仍在扬声器本体外1mm，不能把约3mm算术差当成已证明的维护余量；真实出线点/插头/弯曲及固定需复核。用户40mm实摆证据接受，不由旧79.46mm路线推翻。

上口到电池的约88.16mm绕行只是**条件可达空间示例**，不是最终电池线长要求；电池出线方向未确认，不据该代理路径增加零件或扩大机身。实际可以采用符合出线方向的短路径，需在现有空间内实摆核对。两束、插头和终端预留体均参与整机实交检查，但不等同真实线束BOM。旧代码键名 `protection` 本轮代表完整电池旁2×8×1.5mm的**接头/线束自由空间预留**，不是另加保护板，仍接受原全部碰撞及运动检查。

## 复现、查看与修改成本

沿用报告24的项目独立`.venv`和`requirements.lock.txt`，Python+build123d，无GUI。只读官方仓库仍并列。单命令：

```bash
./scripts/generate-g-v1-95mm.sh
```

参数集中于 `cad/t0/g-v1-95mm-layout.json`；先局部搜索→重建旧版验证相同→新壳→完整原闸门/新增间隙→剖面→通过后STEP/STL/完整装配。新失败会标BLOCKED且不交付新打印网格。旧通用helper仅将下扣stem坐标改为相对基准、给全闸门增加可选线束构造函数；默认旧模型重建差体积0，未删除原检查。

交付见 [模型/图纸目录](../deliverables/g-v1-95mm/README.md)。完整原板装配和同坐标分组在私有Draft新增独立ZIP，普通Draft网页404时使用授权`gh release download`命令，不发布或覆盖旧附件。FreeCAD操作脚本只做查看/视觉分解，不是运动验证或GUI自动化。

成本为重做两片壳、移位原有扬声器/格栅/支撑并调整浅槽；永久零件数量不增。获得4.02%宽度与占地减少，未增加长度或名义厚度。关键承力路径的局部截面保持，但全局面板、真实配件装配和PA12验证成本不能省略。**95.60mm在名义几何上成立；当前为供Reviewer审查的CONDITIONAL候选，不是可正式打印结论。** 不合并、不打印、不修改固件。
