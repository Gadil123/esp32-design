# T0 C 版：嘉立创 PA12 简化装配 / 4 卡扣 + 原厂四安装位定位（开发任务）

> **用户于 2026-10-16 确认的下一阶段任务；状态：尚未实施、尚未打印。** 对应 [Draft PR #3](https://github.com/Gadil123/esp32-design/pull/3)。阅读 `docs/07_cad_measurements.md`、`docs/11_cad_t0.md`、`docs/13_t0_snap_revision.md` 及 Reviewer 第二轮意见后执行。本任务**更新了以前「优先两颗 PCB 固定螺丝」和「7 个外壳卡扣」的设计优先级**；旧 A/B 模型留存用于对照，不能删除/覆盖。

## 1. 不可放宽的用户决策

1. **壳体名义最大厚度 = 12.4mm，包括凸起和全部实际建模零件。** 不采用「USB 加强困难就自动增加到 12.7/12.8mm」的旧建议。可做 12.0mm 探索版，但 12.4mm 是工程主候选。局部 USB 加强如果与 12.4mm、接口通道或可制造性冲突，则保留风险并报告，不要静默变厚或缩小 USB 开孔。
2. **前后壳从 7 个卡扣简化为约 4 个功能卡扣**，辅以必要的非锁紧搭接/定位结构、**一处明确可用的塑料撬片开盖入口**。每个卡扣都是被动弹性扣舌；不增加磁铁、独立翻扣铰链、额外螺丝。卡扣布置须兼顾左侧 USB/TF/侧键孔、右侧电池/扬声器仓及长边接缝，不能只删除三个扣位而不检查间隙和松盖风险。卡扣数量以**4 个为目标**，若因实际几何确实不成立，提供简短理由和最少增量选择，先征询用户。
3. **PCB 首选方案改成「利用原厂四个安装位/金属立柱 + 前后壳的简单 3D 打印定位柱、定位窝、支承台阶」夹持/定位**：不预设一定需要两颗螺丝，也不预设继续保留 4 个弹性 PCB 夹位。
4. 用户接受**装配后必要时少量辅助胶**，包括热熔胶的可能性。但**胶不能作为保证 PCB 不松脱或承载壳体锁紧的唯一设计前提**；必须设计可闭合的基本机械定位。优先考虑安全、低成本、可控、不会损伤主板且尽量可维护的局部固定；高温胶枪会带来局部热负荷，**不得贴软包电池、屏幕、连接器、MIC、天线、密集贴片焊点或活动键帽，不得封死后期维修通道**。只建议在壳体安全区域的少量辅助胶点且实物验证以后由用户决定；不预先 CAD 建模一大团胶或声称热熔胶已通过电气安全验证。
5. **RESET 孔不追求极小：** 不再锁定 Ø1.30mm。优先研究 **Ø2.0 / Ø2.2 / Ø2.5mm** 可打印候选，初始主候选可用 **Ø2.2mm**，但须考虑实际孔径可能收缩、清粉和按压工具伸入；保持 RESET 为**不外露维护键**、不会误按。尺寸由厂商审核与试件结果再最终确定。
6. **材料/工艺：嘉立创「尼龙 PA12 黑色」MJF**；首轮报价前后壳约 ¥43、平台估计约 120 小时发货是用户获得的实时报价参考，不要在 CAD 内当成固定价格。薄壁/小间隙需要基于该材料进行验证。
7. 现有 T0 基准 **壳宽 99.6mm（含两颗外露键总宽 101.5mm）、长 77.86mm、厚 12.4mm** 作为尽量维持的外形目标。不要因为新增定位柱大幅加宽；若碰撞无法解决，报告实测障碍，不擅自改宽/高/厚。
8. 侧键仍为 **BAT_PWR、BOOT 两颗 4.6×2.2mm 外露独立打印键帽，中间 RESET 针孔**；后续 BOOT 可涂/染橙色，外壳黑色。暂不加 Osmo/Action 风格装饰凹线，先确认工艺及装配。

## 2. [P0] 首先验证「四原厂安装位 + 前后壳短柱」是否真能装配

**这里必须优先证明真实机械结构，不允许仅画四根柱子。**

- 从官方原始 STEP 重新确认四处安装位的**可触及方向、轴线、螺母实际体积/Z 范围、是否是 SMT M2.5 螺母/对应孔位的通透性、螺母附近零件和屏幕位置**。已知四轴中心约 `(-20.568,-27.100)`、`(-20.560,32.900)`、`(20.432,-27.106)`、`(20.440,32.894)` mm（USB +Y、SCREEN FRONT +Z）。旧 PCB 固定在前壳靠 4 处弹性夹位；新方案须明确避免前/背面镜像和把 STEP 里的螺母当作不存在的裸孔。
- 设计一种**最简单的、可按 STEP 建模的几何定位方案**，例如前壳局部台阶限定显示模组前向位置、后盖四个低矮圆头支撑/套窝对准原厂金属安装位；若需要前后壳互配的公母短柱，必须证明它们在四处安装位**有真实接触路径和足够横向/轴向空间**。不可假设打印小塑料销直接紧塞金属 M2.5 螺纹孔，或需另在 PCB 上钻孔。
- **PCB 要被限制 X/Y/Z 的晃动、转动和脱位，但不能靠把屏幕玻璃或软包电池压紧来实现。** 区分接触 PCB/金属螺母的支承位置与非受力的屏幕玻璃区域；记录装配公差、失效方向及是否允许少量软质垫/薄胶作为缓冲。
- **说明装配顺序：** 先前壳+键帽、放 PCB/显示模组、连接电池/扬声器、放线、后盖带定位短柱合上、4 个壳体卡扣锁紧；反向拆卸时不能拽坏线束。若 PCB 会随开盖移动，列出其对键帽、显示齐平和扬声器连接的影响。
- 验证**12.4mm 的完整 Z 厚度/间隙**。原厂总装配约 10.22mm，后盖约 1.2mm，但四个原厂安装螺母可能已占据主板最深部。**不能把剩余约 1mm 理论空间当成能够插入 1mm 的完整实心双柱**；需 CAD 测量每处局部净空、可承力位置。
- **备用方案（仅当柱/窝定位不足）**：最多 2 颗螺丝利用原厂 M2.5 安装位，优先固定在前壳并说明夹紧路径、工具可达性和厚度预算。不能跳过首选直接采用两颗螺丝，不能依赖嘉立创 M3/M4 嵌铜螺母服务。若两颗螺丝也无法满足约束，提交证据和简明替代建议，**不要自动恢复 4 个弹性 PCB 夹位**。

**阶段闸门：** 如果四柱定位在官方 STEP 中不可行，优先停下来提供局部剖面与原因，不要把整套 CAD 重写完再发现不成立。

## 3. [P0] 四个外壳卡扣与简单拆盖

- 基于原 A 的 7 卡扣 CAD，选取/重新布置**约 4 个**即可覆盖前后壳左/右边接缝的卡扣，辅以低矮定位搭接边。取消其它弹性梁/接收窗和相关脆弱薄壁。给出位置尺寸表（FRONT USB +Y，REAR 镜像）和一张**实物可理解的装拆过程示意/剖面**。
- **一个释放入口**供指甲或塑料撬片进入；不必有独立可翻转扣板。演示 4 个扣位可以**按顺序释放**，不要仅把四个卡钩同时瞬移到 `released` 坐标然后声称用户能够开盖。
- 保持电池保护板、扬声器格栅及防振、TF 通道、USB、MIC1 预留和原生按键不被压缩/阻断。卡扣数量减少后的接缝翘曲、材料应力/疲劳仍标实物待验，不必做复杂 FEA。

## 4. [P1] 针对嘉立创 PA12 工艺的剩余小修订（不扩大任务）

核对 [嘉立创 3D 打印设计规范](https://www.jlc-3dp.cn/technicalColumnsDetails/27832.html) 和 [PA12 材料信息](https://www.jlc-3dp.cn/technicalColumnsDetails/59512.html)，**区别通用建议、不同 SLS/MJF 规则与实际订单接受条件**。通用参考：凸起/卡扣壁厚建议 >1.5mm，100mm 内尼龙典型尺寸公差 ±0.3mm，孔径可能收缩。不是「每个细节 <1.5mm 都必然报废」的强制判据。

| 区域 | 必要行动 |
|---|---|
| **USB-C 下沿** | 12.4mm 旧模型只有约 **0.880mm** 局部余厚。优先研究**不增加整机厚度**的孔角过渡/两侧短加强、优化局部尖角及裂纹起点；保留真实 USB 插头通过空间。不行则显著标 `MANUFACTURING_RISK`，**不许擅自加厚至 12.8mm 或缩小开孔**。 |
| **RESET 维护孔** | 做 Ø2.0/2.2/2.5mm 参数化候选，避免孔外侧打印成可见矩形导向口；保持遮挡非目标元件，不引入误触；孔径和针具需可通行且便于清粉。使用实际同工艺打印件最后确定。 |
| **侧键** | 保留外露按压面 4.6×2.2、暂保留 1.9mm 外凸；用**独立局部导向槽+键帽配对试样**比较单边 0.2/0.3/0.4mm 间隙；少打印几套即可。检查加宽触头是否会先碰到原厂开关固定外框，不能把 CAD 正重叠当成按键功能 PASS；印刷公差/回弹留待实物。 |
| **后盖、周边薄壁** | 后盖仍约 1.2mm，大面积薄板的翘曲、卡扣根部强度和粉末清理路径按可用空间补局部圆角/低矮筋；**不能用加强筋顶电池**或挤占保护板约 0.23mm 原名义侧隙。没有空间则记录打印风险。 |
| **扬声器格栅** | 当前候选槽宽 0.9mm、槽距 2mm、筋宽约 1.1mm，检查成型与清粉；只有确实干涉/筋过薄才调整，并保持正面出声与实际音腔未知。 |
| **其余** | MIC1 目前无正式拾音孔，进声方向到货才定；TF 外部候选槽必须保留，座入/弹出未实测；MX0/MX1 都朝 PCB 内侧 −X，BAT/SPK 映射、极性和真实插头未知。不要凭猜测消灭这些阻断。 |

## 5. 工程输出、验收和停止条件

开发顺序必须控制投入：
1. **先做「四处安装位定位 + 12.4mm」小范围可行性剖面**（明确是否可以不加螺丝），并检查 4 卡扣可能的位置；遇到实质阻碍，先写报告。
2. 若可行，再在原 PR #3 **增添 C 版参数与 CAD/图纸**，保留已有 A（99.6mm / 7 扣 / 4 PCB 夹位）和 B（104mm / 两 M2）作为可复现对照。不要改动 P0/P1、Pocket OS 软件文档。
3. 生成 C 版**实际 CAD 原比例前/后/侧视 + 关键装配剖面**，提供**材料与零件清单**：具体几个卡扣、几个定位柱、是否需要胶、是否需要 M2.5 螺丝；12.4mm 最大全装配 STEP 包络与关键净空。
4. 同一批交付 **局部 PA12 打印小样 STL**（一处前后壳卡扣、一个 PCB 定位柱/孔匹配、0.2/0.3/0.4mm 按键导向三组、Ø2.0/2.2/2.5mm RESET 孔样）；**每件独立可上传嘉立创报价**，避免多件连杆捆绑导致服务商改变计价或精度。
5. 几何自检只保留关键点：原板与壳体干涉、真正安装/拆卸路径、玻璃不受力、USB/TF 可达、键帽导向与开关接触、全部外壳最大厚度、MJF 最薄/最窄特征标记。**材料弹性、胶黏、真实装配、录音均未验证**，不要用检查数堆砌完成度。

### 退出标准

- C 版首选：**4 外壳卡扣 + 4 原厂安装位被动定位结构**；**无需额外 PCB 螺丝**，无 PCB 弹性夹位（除非真实几何证明必要且报告）。
- 如果四柱定位不成立：**明确列出无法实现的空间/受力原因，再提交备用双 M2.5 螺丝方案的局部 CAD 对照**，不静默转回复杂机构。
- **最大名义厚度 ≤ 12.4mm**，USB 等不可优化的薄壁风险明示。
- 黑色 PA12 作为材料；橙色 BOOT 暂属于配色层面，不增加双材加工难度。
- **保留 Draft；推送 PR #3 待 Reviewer，不合并、不下单、不批准整机打印；禁止 SHA 校验、不过度防御性代码/测试。**

## 6. 交付 Reviewer 时请先回答四个问题

1. 四处原厂安装位在 STEP 中确实允许**壳体定位短柱/窝**而不挤压玻璃、不干涉金属安装件吗？是否需要 2 颗 M2.5 螺丝？
2. 从 7 减到 4 个卡扣后，**如何一步步开盖**？后盖长边如何限制翘起？
3. **12.4mm 是否真正保持**？USB 0.88mm 薄边是否能原厚度补强；RESET 最终哪个孔径只是打印候选？
4. 几套简易 PA12 打印试样分别用于关闭哪些风险，什么仍需等实物到货？

**不要因为一套外壳仅约 ¥43，就省略关键的玻璃受力和电池安全检查；也不要因制造公差不确定就不断增加 CAD 复杂性。**
