# 03 · V1 外壳与装配设计方案（待 CAD 校核）

状态：**结构路线已收敛，尚非可打印模型。** 概念图不能作孔位依据。

## 外形结构

- 微雪 ESP32-C5-Touch-LCD-2.8 整板重新定向，原生 USB-C 朝顶部。
- 正面优先只保留 2.8in 触摸屏，工业风窄/规整边框。
- V1 不增加屏幕下方两颗按钮区，避免机身额外变长。
- 前后壳分体，以螺钉固定并方便反复拆卸；打印材料倾向黑色 PETG，具体打印精度由店家报价确定。
- 无定制主 PCB、无 USB-C 延长线、无按键洞洞板。

## 原生侧键策略

**原则：沿用 PCB 已焊好的三颗轻触开关，利用前后壳合拢限位的独立短键帽（或 RESET 隐藏孔）直接触发。**

| 原生开关 | 外壳操作形式（建议） | 频率/注意 |
| --- | --- | --- |
| BOOT | 可日常触摸到的短按钮帽 | 语音开始/停止的候选；作为固件按键验证 |
| BAT_PWR | 齐平或略凹陷按钮帽 | 电池模式开关机；确保按 2 秒可触发 |
| RESET | 维护针孔，不必做凸起帽 | 避免高频握持误触 |

**结构剖面思路**：手指 → 可更换短键帽 → 原生板载开关，后壳/前壳提供导向和止挡，原生开关负责回弹；不采用细薄的悬臂弹片反复弯折，也不允许胶水承受常规按压力。

第一次打印前须确认开关是否真为侧向触发、按压方向、它与壳壁的净空、行程和键帽的内侧防脱落结构。**不能由板载资源示意图直接推断能顺利安装键帽。**

使用期主要目标为约半年，不为百万次寿命单独研发机构；但必须避免常态卡键、误触 RESET、BOOT 被持续按住影响刷机。

## 麦克风

- 由官方板载资源图确定大致边侧；**拾音开孔精确位置、元件声孔朝向待实物/STEP核验**。
- 只做直接对位开孔，不做从背面绕到顶部的复杂声道。
- 避免掌心覆盖，也避免外壳胶/泡棉堵住声孔。
- 若直孔必须穿过电池或其他硬件，先调整部件位置，而不是默认转向声道。

## 独立扬声器

- 板卡自带音频编解码、功放和扬声器接口，但**喇叭本体是独立的配件**，并非 PCB 固定组件。
- V1 优先背盖上部：直出音孔 + 简单打印定位槽 / 压持方式，必要时薄泡棉防晃。
- 不设计复杂音腔；须避免正反面大缝直接声学短路。
- 桌面平放时确保背部音孔不被完全堵住；可考虑微小支脚。

## 电池和电源

- 仅确定板载充电管理和 **3.7V MX1.25** 接口；电池必须核实实物长×宽×厚、保护板和导线折弯空间。
- 提供可拆后盖和绝缘措施，不允许裸露金属硬件挤压软包电池。
- 电池型号/容量/固定带或支架 **待客服与最终 BOM**，当前所有概念图电池尺寸仅是示意。
- 原生 USB-C 上置，给常见插头外壳、线缆弯折和电脑刷机留足空间。

## 3D 打印低返工原则

1. 官方 STEP / DXF 导入 CAD，建立 FRONT/REAR 区分，确定零件相对坐标。
2. 获取实物或厂家完整尺寸的电池、喇叭、螺丝、按键头。
3. 前后壳采用**螺丝连接**，不要用难以拆卸的隐藏强卡扣当第一版主方案。
4. 首先打印小尺寸公差样件（侧键导向+限位、USB 开口、螺丝柱）；再投完整外壳。
5. 与代打印商家约定工艺、层高、打印朝向、关键尺寸实测与图片验收。
6. 严格区分“概念渲染图”和“带零件装配、尺寸基准、碰撞检查的交付 STL/STEP”。

**V1 完工标准**不是逼真渲染，而是：主板装得下、三个原生键可正确使用/维护、麦克风清晰、扬声器正常、USB-C 充电/刷机可插拔、背盖可打开且电池安全固定。

## 预算（仅规划，非实时成交价）

- 微雪板：实际套餐价待淘宝客服确认。
- 电池和原装/附送喇叭：具体套餐及尺寸待核。
- 3D 打印单套外壳暂按人民币 30–70 的范围询价，实际按材料、打印工时、支撑、最小起步费、运费计算。
- 若总价超过 200，优先削减装饰/处理，不牺牲电池安全、按键避免误触和 USB 插拔可靠性。
