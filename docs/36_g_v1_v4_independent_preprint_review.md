# 36 · 打印前，我对 Pocket Pi V4 外壳的检查报告

2026年10月27日。

## 我的判断

**现在还不建议把这版外壳作为功能样机送去打印。**

我找到了四个需要在送样前处理的严重问题，修好了其中三个：复位孔被挡、USB插头通道被挡，以及检查程序漏报错误。剩下的一个是硅胶按键的位置：**按你提供的尺寸，现有结构没有让它直接够到主板上的小开关。这个机械问题还没有修好。**

这次检查和修复都在电脑模型中完成。我没有打印、下单或推送代码；你实际打印过的V1没有改动。

## 最需要先解决的，是两颗硅胶按键

外面的硅胶按键帽，需要把手指的按压力传到主板上的小开关。你已经确认，希望它直接碰开关，中间不另加推杆。

你提供的卖家图写着：**整个0127按键帽高5.5毫米，已经包含里面的底柱。** 但我从官方板卡模型和外壳模型重新量了一遍，得到下面的关系：

| 要比较的尺寸 | 模型或卖家图给出的数值 |
|---|---:|
| 硅胶帽的整个轴向长度，含底柱 | 5.5毫米 |
| 从外侧压框表面到主板开关 | 约10.38毫米 |
| 两者相差 | 约4.88毫米 |

这里的“外侧压框”，就是用两颗小螺钉固定、负责防止硅胶帽脱出的侧面零件。

**如果按键面露在这块压框外面，5.5毫米长的整颗帽就无法直接跨过约10.38毫米的距离。** 里面的通道虽然是空的，也不能证明胶帽能把开关按下。

这还不是一个“打印后可能紧一点”的问题。它需要先在图纸上解决按键的安装位置、支承位置和触发距离。让按键大幅凹进去，或者假定硅胶能产生很大的位移，都需要新的结构和操作验证；当前模型没有提供这些证据。

我还不能据此画一个可靠的新安装位置，因为卖家图没有让我清楚辨认：胶帽究竟用哪一个面靠在壳体上、从这个面到柱端有多长、允许按下多少。图中的5.5毫米是卖家标注，也不是我拿到实物后测得的值。**随意猜一个位置，可能从“够不到”变成“一装上就顶住开关”。**

因此，这一项目前的处理是：把它明确标成送样前必须解决的问题，并让检查结果如实报告它。**我修了漏报，没有把按键本身说成已经修好。**

下一步应先弄清楚这颗0127的截面和安装基准，再重新安排它与主板之间的位置。现有A/B/C三档小样只改变孔的松紧，解决不了这约4.88毫米的距离问题。考虑到你一次打印要等七天，也没有小规模测试设备，我不会把“先打一轮小样再说”当作默认安排。

## 已经修好的三个问题

### 1. 装好侧压框后，原来的复位孔被盖住了

前壳上有RESET针孔，但盖在外面的侧压框没有对应的孔。结果是：从外面看，针先撞到压框，根本进不到前壳的针孔。

你确认需要在装好外壳后直接复位。我已经给压框补了一个对齐的孔，并重新检查了从外面一直到主板复位开关的完整路线。

加上压框的厚度，针要伸进去约10.38毫米才能碰到开关。原来写的10毫米自由针长不够，我已改成要求至少12毫米。这里说的是针露在手柄外的可用长度，**不表示应该把针插满12毫米**。

修复后的模型中，针可以穿过两层零件并碰到复位开关。真实使用时的针端形状、按压力和安全行程，仍要用实物确认。

### 2. USB外面的孔够大，里面却有一段凸边挡住插头

后盖内侧有一圈凸起，用来帮助前后壳对齐，下面称它为“定位环”。新后盖的定位环伸进了USB插头应该经过的空间。

这个问题很容易漏看：板卡本身放得下，外侧USB开口也没变，但插线时，插头本体还要经过外壁与插座之间的这段空间。按项目原来预留的12.2×6.3毫米插头本体尺寸检查，会碰上这段凸边。

我已经把定位环挡路的部分切掉，外侧13.2×7.3毫米的USB开口保持原尺寸。重新检查后，前壳、后盖和侧压框都没有挡住这个插头模型。

这项修复排除了模型中的遮挡。你的实际线缆外形、打印后的孔缩和插拔手感，仍需要最终试装。V1插线成功的反馈是有效的，但不能替新加的定位环作保证。

### 3. 原来的检查程序会把坏掉的按键孔判为通过

我做了一个直接的试验：**故意把按键孔堵死，再看程序会不会报错。**

结果发现，堵住生产压框的一颗键孔后，原接口检查仍然通过；堵住B档小样的内部通道后，原来的小样检查也仍然通过。

原因是，原检查主要确认“这个三维文件完整、能导出”，没有完整检查“按键真正要经过的孔是不是通的”。一个被堵住的孔，照样可以属于一个格式完全正确的三维文件。

我补上了对完整键孔、内部通道、承托胶帽的台阶、固定孔和剩余材料的检查，并在每次生成时故意堵孔或删掉承托台阶，确认检查程序能发现这些错误。

最终共做了**15次故意改坏模型的试验，全部被识别并拒绝**，包括按键接口、RESET、USB和屏幕开口。临时改坏的模型没有进入正常交付文件。

这让检查程序更可信，但它仍不能替代硅胶手感、塑料强度或真实装配试验。

## 其他部分，目前能确认到什么程度

我直接读取了微雪官方板卡三维文件，其中有723个实体，并用它重新核对外壳。没有沿用前几份报告中的结论作为证明。

目前可以确认：

- **屏幕开口是通的。** 当前模型没有把屏幕盖住的整片封板。
- **屏幕玻璃与上方挡边之间，名义上有0.9毫米空隙。** 前后壳另有自己的接触支承面，理想模型中不需要靠夹住玻璃来锁紧外壳。
- **电池下方的0.2毫米胶层已经画进装配中，位置与电池一致。** 这关闭了“说明里有胶、模型里却没给胶留位置”的问题。
- **后盖的四个壳体螺钉孔、四个主板螺钉孔确实存在。** 仍需确认实际购买的螺钉适配。
- **空前壳沿直线装入的14个检查位置没有发现碰撞。** 这只覆盖规定的直线姿态，还不能保证斜着装、带真实线束装都能通过。

这些结果说明若干明确的几何问题已经排除。它们不能证明打印件一定平整，也不能证明拧紧后玻璃仍然不受力。

## 打印后还需要留意的风险

下面这些列为P2：目前需要保留和验证的风险。按你给的处置范围，我把它们写清楚，没有顺手改动设计。

| 事项 | 对实际使用意味着什么 | 还缺什么证据 |
|---|---|---|
| 前后壳配合 | 定位环每边只留0.15毫米，两件分别打印产生的尺寸误差叠加后，可能过紧 | 明确配合尺寸、工艺误差和是否需要后处理；不能靠螺钉强拉合 |
| 外壳变弯、屏幕受力 | 加厚后盖和加筋有帮助，但不能保证打印后不翘；屏幕也不能用来把壳压平 | 自由放置和锁紧后的平整度、挡边挠曲、玻璃是否受压 |
| 螺钉与反复拆装 | 孔深和螺头有了模型空间，仍可能因实际螺钉、孔缩或扭矩不合适而顶底、开裂或滑牙 | 固定具体螺钉型号，验证拧入和滑牙扭矩、拆装寿命 |
| 电池和线束 | 电池主体有空间，不代表朝屏幕一侧的真实引线不会被夹住；托盘也需要可靠固定电池 | 实际电池、胶材、焊点、线弯折和合壳防夹检查 |
| 麦克风、复位和维护 | 麦克风孔通了，声音仍可能改变；复位针能到，还要避免滑偏和过压；开盖时要能处理线束 | 裸板/装壳录音对比、真实复位操作、完整拆装演练 |
| 文档与文件追溯 | 一些旧表述把已有图纸写成未知，现有校验记录也没有覆盖全部构建依赖 | 后续修正文档和补全输入记录；本轮另存了独立复算证据 |

其中有两个概念值得分开看。

**尺寸误差是“做大了或做小了”，翘曲是“做弯了”。** 嘉立创给的尺寸公差不包含所有变弯情况，不能因为尺寸公差写着±0.3毫米，就认为屏幕周围一定平整。

**达到最小壁厚，也不等于整件足够结实。** 当前屏幕挡边厚1.5毫米、扩展仓前板约1.2毫米。它们的实际挠曲、跌落表现和长期耐用性还没有验证；挡边恰好1.5毫米，也不能写成已经满足“大于1.5毫米”的目标。

### 我怎样独立复算

评审起点是干净工作区的 `d20ac78`。官方资料版本为 `77a7dceac38a1bd491173b3906205217a382c08c`，与项目锚点相符。官方STEP的SHA256为 `73c84092e7d6b55574125d2bf0885a61688514762b796ca43c98dfed1bc18c5c`。

我直接展开官方STEP装配，累积每层零件的位置，再在屏幕平面内旋转180°，没有镜像。完整装配为723个实体；屏、PCB、TF、麦克风、USB和三颗开关的八组包围盒，与 `data/t0_interface_bounds.csv` 一致。也查阅了早期 `data/step_component_bounds.csv`，没有将两份同源表当作两次独立实测。

我分别打开交付STEP和STL，检查零件是否完整、网格是否闭合、两种格式的大小和体积是否相符，再另外检查开口和装配功能。起始前壳、后壳、压框均未穿入官方板卡，但外插线缆和按键动作需要另查，不能由这个结果推断。

屏口整片封板及四角遮挡共5个破坏试验、按键/RESET接口9个、USB挡块1个，合计15个。它们都被对应检查发现。正常文件随后再次读回核对，临时破坏没有写入交付件。

最终又将修复前后的STEP直接比较：后盖变化等同于补切USB通道，去料43.35507 mm³；侧压框变化等同于补RESET孔，去料6.84239 mm³；前壳STL逐字节未变。修复后的完整针路径没有碰壳，与复位开关接触；独立USB插头模型也不碰三件壳体。
