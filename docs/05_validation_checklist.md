# 05 · 采购、机械验证、装配测试清单

当前阶段：**未采购确认 / 未打样**。完成以下门槛前，不得发布“可打印成品 STL”。

## G0 采购确认

- [ ] 淘宝微雪 C5 2.8in 实际 SKU / 是否包括外接喇叭、配线、电池、价格。
- [ ] 客服确认电池长×宽×厚、容量、带保护板与否、线材出口方向、接口极性和连接器。
- [ ] 官方 USB-C 顶部方向下，核实最常见 USB-C 插头的占位空间。
- [ ] 原装扬声器尺寸、线长、外壳背部固定方案。
- [ ] 淘宝打印商家提供 PLA/PETG 用料、最小收费、层高、装配小件公差/后处理价格。
- [ ] 全部 BOM 估价保持 200 元目标并明确超支原因。

## G1 方向确认（**阻塞项**）

- [x] 从原始 STEP 展开装配并提取静态坐标，确认元件位置及背面方向逻辑（USB-C 顶、MIC 左、侧键右）。[解析记录](07_cad_measurements.md)
- [x] 输出 P0 外壳 CAD 的 FRONT/REAR 装配双视图，并用原始 STEP 刚体变换交叉验证镜像；见 [08](08_cad_p0.md)。
- [x] 输出带 FRONT/REAR 标注的双视图，确认 FRONT 按键左 / MIC 右，REAR 按键右 / MIC 左。
- [ ] 不再复用之前错误的侧键方向概念图。
- [x] 从 STEP 测量三键静态包络、中心位置及约 7.82mm 间距。
- [ ] 识别 KEY1/KEY3/KEY2 与 BOOT/RESET/BAT_PWR 的确切映射。
- [ ] 验证侧向活动按帽的接触面与有效行程；静态 STEP 不保证含动态行程。
- [x] 提取 MIC1 静态位置及包络。
- [ ] 确认麦克风实际声孔方向、孔心及外壳开孔干涉。
- [ ] 验证原装喇叭接口与线缆布局、电池背部安装与螺钉柱干涉。

## G2 裸机功能验证

- [ ] USB-C 位于顶部：供电、电脑下载和刷机成功。
- [ ] 画面软件旋转 180°，触摸坐标与界面方向一致。
- [ ] BOOT 键：单击开始录音，再次单击停止/发送或其他预设方式；重启/刷机时不误入下载模式。
- [ ] BAT_PWR：按微雪官方方式长按约 2 秒关机、再次按键启动；断 USB 和只用电池均测试。
- [ ] RESET 正常复位，日常握持不应误触。
- [ ] 板载麦克风裸板近距离测试；遮挡试验确定拾音孔位置。
- [ ] 配套扬声器播放 TTS/提示音，背部出声不被桌面闷住。

## G3 机械结构验证

- [x] P0 已导入官方 C5 原始 STEP，按实际坐标布置基础外壳并检查静态实体干涉；尚未通过实装/打印验收。
- [ ] 两颗可操作侧键（BOOT/BAT_PWR）采用独立短帽；RESET 凹陷针孔；各自有防脱和止挡。
- [ ] 确认键帽不顶住原生开关，开关按下后能够弹起。
- [ ] 确认机身所有边缘防夹线，无电池挤压。
- [ ] 设计可拆卸的螺钉连接后壳，避免靠粘合剂受力。
- [ ] 壳体壁厚、间隙、装配顺序、支持打印朝向通过制造可行性检查。
- [ ] 先打印侧键/螺柱/USB 的小测试样件，再决定整壳打印。

## G4 单套实装验收

- [ ] C5 主板不翘曲、屏幕不受压，接口与螺钉对齐。
- [ ] USB-C 顶部可插拔，开口不刮伤插头。
- [ ] 三颗原生开关可实现预期操作；RESET 防误触、BOOT 可持续正常使用。
- [ ] 声音：麦克风清晰、扬声器不松、不堵塞。
- [ ] 电池安全固定、充电/供电正常，壳体无异常发热。
- [ ] 拆开重新装回不会损坏按键帽或折断脆弱卡扣。
- [ ] 留实物照片、CAD、STL/3MF、最终 BOM、供应商和金额，更新 README 状态。

## 当前主要风险

| 风险 | 严重程度 | 应对 |
| --- | --- | --- |
| 官方资源图前后视角混淆 | 高 | 双视图 CAD + 正反两张图 |
| 麦克风声孔/出声孔错位 | 高 | STEP/实物核对后开孔 |

| USB-C 顶部插拔干涉 | 中 | 保留插头壳体/拔插空间 |
| 三键寿命与键帽手感 | 低至中 | V1 半年试用目标，无复杂机构 |
