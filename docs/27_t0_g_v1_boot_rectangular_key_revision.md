# G-V1 任务26：BOOT圆角矩形一体片

对应 [任务26](26_t0_g_v1_boot_rectangular_integrated_key_task.md)。开发基线为 `e805d38`；只修改KEY2/BOOT形状及其必要的局部刚性止挡。BAT_PWR仍为原L形，RESET/TF/后盖/四螺丝/外形/临时配件不变；E、旧G与Pocket OS冻结。不合并、不下单、不批准打印。

新文件在 `deliverables/t0-g-v1-boot-rect/`，旧 `deliverables/t0-g-v1/` 和局部成果不覆盖。旧版完整STEP与新版完整STEP的取得和FreeCAD查看见 [下载与Viewer说明28](28_g_v1_private_download_freecad.md)。不是把整板STEP提交给打印厂。

完整外形尺寸99.60×77.86mm、玻璃/FRONT齐平和12.4mm名义上限保持。可见外形是整个长弹片，不虚称只有一个独立方形键帽；长臂没有藏到双层机构中。

为给下移后的矩形片建立非玻璃止挡，仅BOOT的原两块刚性肋改为**上方连接脚＋止挡柱**：连接脚Z−3.7…−2.9、厚0.8mm；柱X厚0.9mm、沿Y宽1.2mm，位于原键中心Y−2.5…−1.3。它避开凸点Y范围，不留下直接下移旧止挡时会出现的0.05mm活动细缝。止挡不承诺真实开关过行程安全；柱自身刚度、梁末端继续弯曲及允许按力都待实测。

## 有限验证与结果边界

从原始官方STEP重新累积occurrence位姿、绕Z180°建立 USB+Y / FRONT+Z / REAR−Z。完整723物理实体参与检查；没有用包络替代原板碰撞几何。

先运行局部闸门，确认新前壳单实体有效、原板安装静态与连续REAR±Z装拆不碰两键/凸点/止挡。BOOT检查静止、0.4、1.4及止挡后0.03mm的候选姿态；非目标722实体全部保留。原生KEY BRep不可拆分为已证实的活动头/固定框，面外固定框检查仍为代理；与整块KEY相交不是实际触发证明。返回0位移只表示几何复位姿态，未证明PA12回弹。

BOOT允许变更区为 X[−29.6,−25.5] / Y[−33,−15.8] / Z[−10,−0.2]mm。与冻结旧前壳作布尔差，变更区之外体积必须为0；正式整壳再对比原后盖对称差为0。因此BAT_PWR、TF、RESET及其他壳体不能悄悄改动。

局部通过后复用原两浅扣/四螺丝的完整整壳路径检查及后盖刚体厚度包络，导出真实新前壳STEP/STL、739实体完整装配和轻量模型。后盖不重复改造，新版与旧版使用同一后盖文件。精确查看包只省略官方零厚度参考面，**723原板物理实体全部保留**；模型各物理关系不变。

实际数值见 `local_checks.json` / `checks.json`。本轮没有材料FEA、试样系列或新的按键机构搜索。所有单位mm，STL保留装配坐标。

### 刚度与风险，不能把几何PASS当PA12寿命PASS

同材料、同厚度、同11mm有效长的线梁近似下，Z截面高度由2增为3mm，弯曲刚度约为旧梁**1.5倍**。根应变近似仍为 `1.5×1.2×1.4/11²≈2.08%`；0.4mm约0.595%。这不等于按力不变或手感更好，也未证明许用应变、疲劳或打印方向安全。新矩形梁与原键高度对齐，旧L形自由端的Z偏心减小，但真实三维应力和过压仍未验证。

仍保留嘉立创通用工艺限制及薄特征风险：1.2mm叶片、0.8mm凸点、0.8mm连接脚、0.9mm止挡不是厂商已接受的制造尺寸。指腹若覆盖固定根/邻近固定壁可能使操作费力；图上标出自由端按压位置，人体可达/按力须实物确认。

### 既有失败工况不删改

止口0.20＋螺孔0.15＝PCB相对前壳可达+X0.35mm；再假定凸点端部缩短0.30mm。按既有1.4mm参考止挡，原两键仍有约0.054–0.056mm正间隙。新BOOT未通过增加凸点长度或虚构开关行程来关闭它，完整检查继续报告 `BLOCKED_CONDITIONAL_PRINT_FIT`。

反方向的增材/偏板装入、真实活动头与容许过压仍是Reviewer指出的待闭环风险；本轮没有宣称原有双向制造公差已解决。文档25中“数百牛顿夹紧自动居中”“一定由弹性吸收缺口”“精确1.36N”“低于0.08mm缩水”“允许打印”等结论没有本机实测支持，**不作为本轮验收或用户打印授权**。未默认实施0.12mm凸点加长。

MIC1声口/声路、真实插头/线束服务余量、临时电池/扬声器、四处1mm PA12承座的扭矩/蠕变、实际螺纹啮合与总厚度制造偏差均沿用未验证门槛，不在本次BOOT外观局部修订中关闭。
