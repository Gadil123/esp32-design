# T0 A 纯卡扣修订：Review only

本轮执行 [任务书](12_t0_post_review_revision_brief.md)，保留 [B 原基线](11_cad_t0.md) 的参数、导出及大文件附件。本文件描述新增 A；任务书本身仍是需求记录。四处 PCB 夹位仍在前壳上，与合壳卡扣分开。没有修改 Pocket OS 软件路线、P0/P1 分支，也没有增加电子器件。

## 宽度与连接方案

| 项目 | B 原双 M2 基线 | A 纯卡扣 |
| --- | ---: | ---: |
| 壳体宽 × 长 | 104.00 × 77.86mm | 99.60 × 77.86mm |
| 含 1.90mm 外露键的完整宽 | 105.90mm | 101.50mm |
| 完整名义厚度候选 | 12.0 / 12.4mm | 12.0 / 12.4mm |
| 独立打印零件 | 两壳 + 三个活动推杆/键帽 | 同左 |
| 额外合壳金属件 | 2 M2×8 + 2 螺母 | 0 |
| 壳体周边卡扣 | 上下边共 4 | 原 4 + 右长边 2 + 左长边 1 |
| PCB 独立夹位 | 4 | 保留原 4 |
| 局部导向/接触 | 每侧游隙 0.50；短触头 1.4×0.6 | 每侧 0.20；短触头 1.8×1.2；收紧边框内固定导向 |

**缩宽 4.40mm，而不是把最初的 7mm 全归因于螺柱。** 取消 B 两个 Ø7.2mm 螺柱及螺母装入槽后，右侧结构不再受螺柱最右 X=73.30 的包络约束。但保留电池中心 (48.4,14.5)、34×50×5 电池、保护板、扬声器、插头及两条 Ø1.50 临时线束后，保护板最右 X=68.10。它到右壁需至少 0.15mm 名义刚体间隙，加 1.80mm 壁和左边框 X=-29.47，固定布局下界为 **99.52mm**。取 99.60mm，保护板到右壁 X 向净空 **0.23mm**，到后盖任意部分的最小距离为 0.20mm（底面）。这是当前临时布局的收敛值，不是全局最优，也不是给真实线端留足的证明。97mm 右壁会与保护板发生 17.16mm³ 的真实体积重叠，报告中保留该否定检查。

卡扣梁沿边框布置，候选长 12、厚 1mm、释放 0.8mm。右边自由端 Y=-17/+30，覆盖扬声器和电池区的长接缝；左边自由端 Y=+28，避开 TF 通道及三键区。两个非锁紧定位台阶位于右侧 Y=-6/+35，控制闭合错位，侧面留 0.2mm 候选间隙。台阶不承担软包夹紧力。接收窗向边缘开放，可从接缝接近扣头后朝内释放；右侧向 -X、左侧向 +X，上下边向机内。开盖朝 REAR -Z 退出。

**这些结构仍非制造合格。** 右侧两个扣位与定位台阶改善长边约束，却不能证明长缝不会翘起。左边接口占据了下半段，不能为了增加扣位削弱 TF/键孔薄壁；当前保留这段翘曲风险。释放入口是接收窗，不额外添加活动搭扣；工具与手指实际可达、是否需同时释放多个扣、根部圆角/缺口敏感、材料应变、打印变形、磨耗和反复拆装均 `unverified`。线性应变估计不能代替实测。原 B 螺母装入/工具保持风险原样保留，A 取消的是该紧固结构本身。

## 键帽与功能门槛

FRONT、USB +Y 朝上：**KEY1 → KEY3 → KEY2**。暂映射 BAT_PWR → RESET → BOOT，功能身份仍待实板确认。只有上下两键外露，每颗按压面 4.6×2.2、圆角 0.35、外凸 1.90mm；中间 RESET 仍为 Ø1.30 针孔和内凹 0.35mm 的独立活动推杆。

额外发现：B 原模型虽有 Ø1.30 的圆柱切口，但 RESET 主体导向切口起点为 `recess 0.35 - clearance 0.50 = -0.15mm`，已穿出外表面，实际可见矩形口约 2.8×2.4mm。原 B 图纸/说明的“只有针孔”并非其实际几何，本轮保留 B 文件作为风险对照，准确图纸明确标识这个差异。A 将主体导向起点放到面后 0.80mm，保留真实外侧材料和 Ø1.30 孔；独立 RESET 推杆增加 Ø0.70、长 0.45mm 的短圆鼻，鼻面仍内凹 0.35mm。此短鼻也需供应商验证，不能视为 FDM 合格。

RESET 候选装配顺序是**先于 PCB 安装**：从后方接近时沿 +X 内移 0.50mm，使圆鼻避开面后 0.80mm 区，再沿 -X 就位至针孔后方；随后装 PCB、最后扣后盖。该平移只发生在没有 PCB 的装配阶段，绝不是假定开关行程 0.50mm。局部对照记录后方进入及最后平移的碰撞结果，手工可达和实际装配仍未验证。

A 的推杆、法兰、渐缩段和短触头是一体活动打印件。收紧边框内原有固定导向，导向到主体末端，法兰滑动腔在其中作局部避空；两端有实际导向承托，前后两壳分别形成导向的一部分，不能把活动推杆画成壳体的一部分。保持 1.8×1.4 主体、4.2×3.0×1.0 法兰与 1.0mm 短触头投影；触头加宽至 1.8×1.2。导向每侧间隙减到 0.20mm。

新报告单列 `key_contact_reliability`：依据真实 CAD 活动面/触头尺寸、两端导向站位及相反方向间隙，估计保守偏转界，再计入候选 0.4mm 轴向预算的触头悬伸。对 Y/Z 四角计算重叠，扣除倾斜投影缩短和跨轴剪切；当前三个键的最小活动面面积重叠比例约为 KEY1 59.6%、KEY2 59.5%、KEY3 44.2%，原 B 的保守最坏界可降为 0。RESET 外端使用圆孔/圆鼻真实半径差 0.30mm，内端使用主体每侧 0.20mm，不能把两端都算成 0.20。该模型是导向几何筛查，不是实际开关操作测试。`full_pad_coverage_gate` 严格要求整个触头投影始终落在活动面内，而不是仅有正重叠；A 加宽触头后此严格条件仍失败。另外检查四个纯侧移角点在两壳中的连续轴向包络。**触头全接触门槛仍为 FAIL；正重叠也只允许 FUNCTIONAL_UNVERIFIED，绝不据此称按键功能合格。** 固定开关壳体处的倾斜接触力、真实开关行程、回弹、偏心摩擦、是否误触均未证明。

0.20mm 导向间隙低于继承的 SLA 通用 0.50mm 动件参考；原 ±0.20mm 尺寸误差再扣清理余量后没有剩余配合裕量。报告将此条件公差筛查保留为 **FAIL**，从名义刚体几何与局部最小特征筛查中分开，不能掩藏于总 PASS。需要供应商可实现的局部配合/清理方案与试样，否则该导向不能放行。SLA 脆性/收缩、SLS/MJF 粗糙面和粉末清理、FDM 层向/小头强度都仍有限制；本轮没有选定工艺。

**1.20mm 低凸起只作候选**：保持 4.6×2.2 按压面，把头厚改为 0.60、头后运动空隙改为 0.60，合计外凸 1.20；并非简单把原 0.90 空隙压成 0.20。0.4mm 候选运动后的名义头后间隙由 0.50 降至 0.20，头也更薄，条件误差预算不通过。勾挂可能减小，但指腹可达/误触没有实测；不替换 1.90 主候选。局部候选 STEP/STL 和独立比较报告可查看，不把它当完整装配验收。

## 图纸和检查的边界

原比例 `orthographic.png` 的 FRONT、LEFT、REAR 使用相同 mm 比例，USB 始终 +Y 在上，REAR 的左右确实镜像。屏幕按原厂完整 DISPLAY 渲染，侧舱保持真实宽度。`key_sections.png` 标注局部放大/不按整机比例，分开两颗外露键、隐藏 RESET 与固定导向；`long_edge_sections.png` 分开 PCB 独立夹位和壳体周边扣。所有图均由 B-rep 裁切/三角化生成，没有图像生成或依据效果图定孔。

A 的 12.0/12.4 两版各有 175 项名义几何检查通过；项目数较 B 减少主要因为取消四件金属紧固件及相关两两碰撞组合，不代表少检查原板或配件。条件制造预算失败和功能未验证另列，不计作“全通过”。完整 STEP 回读均为 738/738 有效实体（723 原厂 + 15 新件），最大厚度分别 12.000/12.400mm，完整平面包络均为 101.50×77.86mm。导出回读结果见各版 `checks.json`，单件 STEP/STL 继续检查实体有效与封闭性。

完整检查继续覆盖原厂所有实体、两壳、三帽、电池/保护板、扬声器、泡棉/胶/阻尼、两个临时插头和两条线束；A 不再带 M2 实体。厚度包括所有已建模实体，导出后回读量测。原板装入使用松开 PCB 夹位的保守连续包围盒；后盖装配仍是五个释放扣位的刚体姿态，不是弹性或有线动态装配证明。正重叠不代替功能，通过姿态不代替材料强度。

12.0mm 的 USB 下薄边仍约 0.480mm，12.4mm 仍约 0.880mm；没有缩小 USB 开口或独立插头探针。真实插头鼻/肩/座入仍待验证。PCB 前限位片 0.8mm，距 PCB/LCD 各约 0.1mm；两零件各 ±0.2mm 的条件位置偏差可把 0.1 变成 -0.3mm，不能批准该配合。12.4 是优先工程对照，12.0 是挑战版；11.5 的必要净空失败记录保留。

MX 插座均向 PCB 内侧 -X；上座→扬声器、下座→电池仍为临时映射，没有确认配对插头、极性、线端、弯曲半径或真实安装顺序。MIC1 只有保留空间，没有正式声孔；进声方向、PCB 声学通孔、裸板/装壳录音及扬声器串音仍阻断。TF 仅保留免拆盖候选外部通道，座入/弹出/指甲可达未证明。原厂 Wi-Fi 天线避让与实测仍待确认。
