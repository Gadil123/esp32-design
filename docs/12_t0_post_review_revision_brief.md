## 一、用户确认的方向（这轮新增）

1. **前后壳首选方案 A：纯卡扣。** 用户认为为两颗螺钉牺牲整机宽度不划算，希望借鉴 FoloToy AI Passport 的**周边弹性扣舌 + 定位凸台 + 方便撬开/释放的接缝**，不要求复制其未经核实的具体扣位尺寸。AI Passport 公开拆解能证明纯周边 snap-fit、无螺丝/封壳胶，**不能证明存在像乐扣保鲜盒一样的独立可翻转把手**。不要自行增加磁铁、铰链、活动搭扣或其它复杂零件。
2. **保留原 T0 的 PCB 固定逻辑：** 4 处**与前壳一体成型的弹性 PCB 夹位**独立固定原厂 PCB；PCB 夹位和**前后壳周边卡扣**是两套不同的机构。后盖取下后 PCB 仍留在前壳中。不要将这两套卡扣混为一谈。
3. **按键要以真实 CAD 而非自由生成的效果图为准。** 两颗外露的小型侧键（BAT_PWR、BOOT）+ 中间一个隐藏 RESET 针孔；外露尺寸本身用户认可为协调，**不要求放大、做成三个大按钮或新电子开关**。1.9mm 外凸量可作 1.2mm 低凸起候选对比，但**不要擅自把 1.2mm 定为最终尺寸**。
4. **整体目标仍是紧凑、简单、可拆、低成本，厚度约 12mm。** 12.0mm 名义几何挑战版及 12.4mm 工程对照版都应保留；不为视觉效果或不必要功能加大尺寸。没有实物与材料证据前，**不得批准打印/合并 PR**。

## 二、需开发处理的项目与验收标准

### [P0-A] 纯卡扣前后壳变体 + 真实宽度优化

**当前基线（不是新方案）：** 前后壳 4 处周边卡扣 + 右侧扩展仓 2 颗从**背面垂直拧入**的 M2×8 低头螺钉（非右边框横向拧入），含螺母和两根约直径 7.2mm 的螺柱。外壳 `104.00 × 77.86mm`；外露键帽向左额外延伸 1.90mm，完整平面包络 `105.90 × 77.86mm`。最早约 97mm 的宽度是构想初值，当前增加约 7mm 的原因包括**螺柱 + 电池保护/定位 + MX 插头绕线**，不能声称「去掉螺柱就必然省回全部 7mm」。

**任务：**
- 基于 PR #3 已可复现的 T0 参数化 CAD，新建**纯卡扣布局变体 A**（不覆写/删除现有双螺钉基线 B）。移除两颗外壳 M2、螺母、螺柱及装入槽；**不要删除四处原厂 PCB 弹性夹位**。
- 重排/增加合理数量的**前后壳周边弹性卡扣和非锁紧定位台阶/搭接边**：重点解决取消右侧 M2 后**右侧长边中段**的闭合与接缝翘起风险，同时核查左侧中段。左侧有 TF 孔、两个外露按键、RESET 孔，避开相互冲突的薄弱部位；USB 顶部仍可直接插拔。
- 设计一个可用薄塑料撬片/指甲接近的**可拆卸释放入口**；优先一体打印卡扣，不新增活动扣板/金属配件/磁铁。不能仅删除螺钉并假设原四个上下边卡扣已足够。
- 在**不改变右舱电池与扬声器平面分区、真实官方主板、玻璃齐平、麦克风保留区和接口占位原则**下，参数化探索尽量缩窄宽度：**以约 97mm 为尝试目标，不是必须实现的虚假 PASS**；若因为真实临时包络需要 >97mm，报告相应的最小可行宽度与约束。
- 给出对比表：B 双 M2 基线宽 104mm、A 纯卡扣宽度、含左侧键帽的最终宽度、右舱最小净空、卡扣/接缝的假设与打印材料风险。务必将**螺柱移除节省量**和**其它电池/插头/布线约束**分别解释，不能简单把 7mm 全算在螺丝上。
- 输出 A/B 的**真实几何**正面/背面视图、周边扣与 PCB 夹位剖面、关键装配/拆卸动作说明；检查真实干涉、局部壳体厚度和翘曲风险。可制造性/弹性/手动释放只能标 `unverified`，不得用刚体几何 PASS 冒充强度 PASS。

**验收：** A 与 B 都可复现、可比较；纯卡扣变体的宽度收敛有可追溯理由；不破坏 PCB 独立定位、按键、TF、USB、右舱结构或 12/12.4mm 厚度定义。

### [P0-B] 侧边原厂按键/3D 打印键帽：纠正细节、补偏心可靠性

**CAD 中已证实的当前形态，必须作为图纸基准：**
- 官方 PCB 上保留**三颗原厂轻触开关**，不增加新电子按钮或焊接。
- **屏幕 FRONT、USB 向上时，左侧由上向下的真实空间顺序：KEY1（暂映射 BAT_PWR）→ KEY3（RESET）→ KEY2（BOOT）**。电气功能身份/实际动作仍待实板核实；不要按 KEY1/KEY2/KEY3 编号直接假设空间顺序。
- **只有 BAT_PWR 与 BOOT 外露：** 每颗外露按压面 `4.6mm（沿机身长边 Y）× 2.2mm（沿机身厚度 Z）`，圆角半径候选 `0.35mm`，静止时相对于壳体左边框平面**外凸 1.90mm**（由 `key_head_motion_gap_mm=0.9` + `key_head_depth_mm=1.0` 构成）。在 12.4mm 厚度侧视里只占 **约 17.7% 的高度**，不是三个大键。
- **RESET 中间只露出 Ø1.30mm 小孔**（`reset_hole_radius_mm=0.65`）；其独立打印的内凹推杆并非外露大键帽，候选凹入 `0.35mm`。
- **每个打印键帽是一个独立的一体零件**，内部包括外侧按压头（外露两键才有）、细长加粗主体、**防脱挡肩/法兰**、渐缩部及最内侧短触头；**推杆不是前壳上长出来的刚性零件**，而是随键帽移动。前后壳中挖出的导向孔、滑动腔、挡肩限位腔属于**外壳一体成型**。该机构应从后方装入，沿 X 向 PCB 轻触开关传力。
- 其它现有基准：挡肩约 `4.2×3.0×1.0mm`，主体横截面 `1.8×1.4mm`，短触头截面 `1.4×0.6mm`，轴向候选运动 `0.4mm`，实际开关行程**未知**。
- 沿长边三键中心间距约 **7.82mm**，两个外露键的外边缘总跨距约 **20.2mm**，相对于机身长边 `77.86mm` 的占比约 **26%**。

**必须修正/检查：**
- 已知旧 P1 继承风险：`key_guide_clearance_mm=0.50mm/side`，触头与原厂活动面的边缘余量仅 `Y≈0.20mm、Z≈0.10mm`，报告中 `full_contact_coverage_for_all_guide_float=false`，而局部 feature check 为 PASS。**最不利偏移/倾斜可能失去有效触发接触。** 对此建模最不利侧向游隙与触头重叠，适当优化导向、限位/短触头尺寸，提供 `FAIL` 或独立 `functional_unverified` 门槛；不要因为形状合法就写「三键功能合格」。
- 同时研究 **保持 4.6×2.2 按压面、外凸约 1.2mm** 的低凸起候选，和现有 1.9mm 基线对比按压可达、可动行程、装入顺序、防脱挡肩、外壳剩余壁厚、误触/勾挂与公差。**优化候选，不等于用户已接受量产尺寸。**
- **严禁沿用此前 AI 自由生成的外观/剖面图作为证据**：那些图曾把 RESET 画成外凸第三键、把活动推杆画成前壳一体件、把原板按键尺寸放大、把整机高错画成 58mm、把屏幕画到几乎占满侧舱。今后的图须由 CAD/STEP 实体、正确坐标系和尺寸标注**直接生成**。至少提交**按实际长宽厚比例的整机正面/左侧视图**、**三键区域放大图**、**外露键与 RESET 分别的局部剖面**；按键零件与固定导向必须用不同颜色标注，放大图须显著标注「局部放大／不按整机比例」。
- 不用图像生成替代模型，也不要无需要求大量外观变体。

### [P1-C] 12.0mm / 12.4mm 厚度与 USB、PCB 限位的制造边界

- 当前 12.0mm 和 12.4mm **完整 STEP 名义几何均 PASS**，不等于可制造。12.0mm USB 下沿约 **0.480mm**，12.4mm 约 **0.880mm**；后者满足报告中使用的**局部** SLA 0.8mm 壁厚筛查，但**整机没有工艺放行**。
- PCB 前限位片厚约 0.8mm，与邻近 LCD/PCB 名义间隙约 0.1mm；打印误差和原板公差不能被忽略。11.5mm 原板/后盖必要净空失败，仅保留探索记录。
- 研究纯卡扣优化后两厚度真实变化；不能以去掉 M2 就自动宣告可以压薄。保持 12.4mm 为**优先工程对照**、12.0mm 为**持续挑战候选**，两版都不是打印批准。
- USB-C 需真实插头鼻/肩台包络证明；不可仅缩小探针/开孔、虚化局部边缘来制造 PASS。

### [P1-D] 接线、电池/扬声器、MIC1 和 TF：保留必要阻断

- 两颗原厂 MX1.25 横向座的**插口空腔都朝 −X（PCB 内侧）**，不是直接朝右舱。现有 CAD 使线束先朝 PCB 内侧走、再弯曲绕回右舱；**实际插头、护套、线径/弯曲半径、装拆空间、接线极性以及上/下座对应 BAT/SPK 身份未确认**。当前上座→扬声器、下座→电池是**暂时映射**，切勿据此给出焊接或通电指令。若移除 M2/缩窄右舱，要重跑这些临时线束体积的干涉检查；更换真实配件后重建。
- 电池临时 `34×50×5mm`，扬声器临时 `30×20×6.8mm` **都不是实物确认尺寸**。侧舱电池浅定位、软包不得受夹紧力；扬声器正面格栅、周边泡棉及背面候选阻尼照常保留；不要为新的纯卡扣结构挤占电池膨胀余量或扬声器密封。
- **MIC1 目前没有前/后壳正式拾音孔**。原始 STEP 是无声孔细节的简化包络，保留 MIC1 安全空间；到货确定进声方向、是否有 PCB 声学孔，再选择**短直有效声道**。现在不能擅自打正面/背面孔，也不能声称已具语音输入能力。
- **TF（Micro SD）已有外部候选通道**，但实际插到位、弹出行程、手指/指甲取卡性尚未证明；必须保留从侧面**免拆盖插拔**这个需求，等实物后做功能检查。
- 外部 USB、两侧键、RESET 针孔、TF 通道及未来 MIC 声路不可被新卡扣/缩窄结构遮挡。
